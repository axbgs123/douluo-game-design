<p align="center">
  <strong>如果你真的穿越进斗罗大陆，六岁觉醒之后的人生应该由你来过。</strong>
</p>

《未定之书》是一款覆盖斗一至斗四时代的本地单人互动小说 RPG。你创建的不是站在原著主角身后的旁观者，而是一个有身世、武魂、监护关系、资源和秘密的原创人物。觉醒之后要不要隐藏第二武魂、去哪里上学、跟谁学、怎样取得第一魂环、是否加入势力，以及要不要介入那些熟悉的历史，都由你决定。

游戏会先结算这个世界真实发生了什么，再让 AI 把结果写成第三人称限知的中国男频小说。时间、成长、魂环、战斗、资源、关系、NPC 行动和历史因果都由程序负责；AI 不能替玩家答应拜师、凭空送机缘、偷看隐藏武魂，也不能一句话改变胜负和数值。

> **项目状态：Private、持续开发、非商业同人原型。** 四时代核心规则已经可玩，但它还不是完成品，也没有取得《斗罗大陆》相关 IP 的公开发行或商业授权。原著还原、长篇文笔、自由行动覆盖和数值平衡仍在持续验收。

## 这局人生会怎样展开

1. **先决定你是谁。** 选择斗一至斗四时代，抽取或指定身世与武魂，再完成姓名、性格、觉醒和人生目标。
2. **处理觉醒后的现实问题。** 天赋越高，越可能引来复测、培养争取、资源倾斜、监视和敌意；不同家庭与势力会提出不同条件。
3. **用自然语言行动。** 你可以直接输入“问父亲家里能负担哪所学院”“暂时隐藏第二武魂”“去市场准备猎魂补给”，也可以使用时代面板、任务、地图和战斗按钮。
4. **让关系和世界继续运转。** NPC 不会停在原地等玩家，错过的地方事件也会留下物价、治安、声望、伤亡或势力后果。
5. **成长并承担代价。** 修炼、猎魂、战斗、职业、经营、机构履历和关系都有结构化状态；强大的金手指、魂骨与超限魂环同样有使用条件、暴露风险或次数限制。
6. **改变历史，而不是删除原著。** 重要事件会保持惯性。只有玩家取得情报、到达现场、准备资源并形成足够因果，后续时间线才会延后、替代、取消或出现新的连锁结果。

游戏同时提供三条实时 AI 推荐行动，分别偏向成长与资源、关系与势力、秘密与风险。推荐只是此刻可执行的方向，不会替玩家自动选择；你始终可以输入自己的行动。

## 为什么它和普通 AI 角色扮演不同

| 普通 AI 角色扮演的常见问题 | 《未定之书》的处理方式 |
|---|---|
| 模型说成功就成功，状态前后矛盾 | 程序先结算魂力、伤势、物品、金钱、关系与胜负，模型只能叙述结果 |
| 上下文变长后忘记旧事 | SQLite 二阶段向量检索：先找相关章节，再召回具体场景 |
| NPC 偷看隐藏武魂或未来剧情 | 原著知识、角色记忆和模型输入都按时代、日期、来源与玩家知情范围过滤 |
| 原著事件不顾玩家影响强制发生 | 事件按硬前置、催化条件、并列结果与观察路线建模，玩家因果会向后传播 |
| 三个选项只是同一句话换皮 | AI 实时生成“成长 / 关系 / 风险”三类行动，并在展示前用克隆存档预跑规则 |
| 重写后不知道改了什么 | 正文、召回内容、提示词、审校问题和采用版本都可在本机查看与重放 |

## 开始游玩

### 1. 启动游戏

需要 Node.js 24 或更高版本。

```bash
git clone --branch codex/iterative-optimization --single-branch https://github.com/axbgs123/douluo-game-design.git
cd douluo-game-design
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`，在“模型设置”中填写兼容 OpenAI 接口格式的模型地址、模型名和 API Key，然后创建角色。密钥只保存在本机 `.data/deepseek.json`，不会写入 Git 或返回网页端。

不配置模型也可以创建和查看角色，但正式自由行动需要模型完成意图整理和小说叙述。

### 2. 完成局外准备

“局外成长”包含武魂召唤、身世召唤、遗物获取和仓库。抽到的武魂与身世可以在不同存档中永久重复使用；身世池最低为紫色，并设有金、红、七彩独立保底。局外选择会改变开局候选，但不会让 NPC 无条件接受玩家，也不会跳过世界规则。

### 3. 创建角色并觉醒

选择时代和性别后，从三名候选中挑选或继续刷新。候选页会说明身份带来的资源、义务、关注和风险。随后完成姓名、性格塑造、觉醒与人生目标；双生或三生武魂的品质保持同级，每个武魂拥有独立修炼和魂环账本。

### 4. 推进故事

- **自由输入**：适合交谈、调查、修炼、生活安排、交易和明确的个人行动。
- **系统按钮**：适合战斗、猎魂、学院或宗门事务、时代专属成长，以及需要严格结算的多阶段任务。
- **任务与时代面板**：显示眼下能实际推进的条件，不要求玩家猜隐藏关键词。
- **地图与手记**：地图负责可达地点与旅行，手记只汇总角色已经知道的关系、任务、消息与线索。
- **设置与诊断**：查看本轮向量召回、正文版本和审校结果；重放不会推进存档。

自由输入如果缺少专用结算、违反角色知识边界或当前确实做不到，会被规则拒绝或给出可执行的替代方向。拒绝不是小说模型临时编造的失败，而是为了防止“说一句就得到一切”。

## 核心设计

### 程序决定事实，AI 负责叙事

每次调用叙事模型前，程序会编译并审计 `narrative-logic.v1` 逻辑合同，锁定原著年代与地点、人物欲望与知情来源、制度权限、可用资源、在场反应、程序后果和必须留下的状态变化。逻辑包失败时不会调用模型，也不会用反复重生成掩盖确定性缺口。

正向 `generationContract` 会进一步给出场景目标、必写节拍、允许事实、禁止声明、时代语言和停笔边界。私下测试隐藏武魂时，模型请求会直接移除无关 NPC 与见证者，而不是等正文写错后才拦截。

### 三层检索守住长篇连续性

生成前会分别检索：

1. **存档记忆**：每个存档最多保存 2,000 条场景，先选最多 3 个相关章节，再召回最多 8 条旧事。
2. **原著知识**：按时代和日期召回人物阶段、关系、势力、地点、事件与魂兽资料，区分“原著 / 原著归纳 / 原创”。
3. **世界逻辑**：召回天赋反应、资源交换、秘密传播、敌对升级和人际交往规则。

结构化状态始终高于向量召回；玩家未知的秘密和未来事件不会进入模型输入。详见 [`docs/vector-memory.md`](docs/vector-memory.md)、[`docs/canon-knowledge-vector.md`](docs/canon-knowledge-vector.md) 与 [`docs/world-logic-vectors.md`](docs/world-logic-vectors.md)。

### NPC 与世界不等待玩家

具名 NPC 使用欲望—责任—信息—权限—资源规划器，会按自己的职责执行训练、调查、保护、组织事务和对抗计划；缺少路线、许可或资源时也会失败。地方事件即使被玩家拒绝或错过，仍会改变供需、治安、关系、势力、生态与后续任务。详见 [`docs/npc-planner.md`](docs/npc-planner.md) 与 [`docs/event-consequences.md`](docs/event-consequences.md)。

剧情导演则用“立局—主动推进—阻力显形—局势扩大—阶段兑现—不可逆转折”组织主线。阶段必须由真实行动和状态证据推进，不能靠回合数或旁白自动升级。详见 [`docs/story-director.md`](docs/story-director.md)。

### 每一轮生成都可以追溯

成功回合会只追加保存完整正文、玩家输入、程序结果、章节归属、版本和 SHA-256。设置页可查看本轮实际召回的旧事与原著资料，也可以只读重放审校，或使用原始提示词重新调用模型作对照；所有重放都不会推进存档。

## 当前可玩范围

新游戏可以独立选择四个时代：

| 时代 | 起始纪年 | 专属成长系统 |
|---|---:|---|
| 斗一《斗罗大陆》 | 原作 0 年附近 | 学院、宗门、猎魂、魂环与原作事件干预 |
| 斗二《绝世唐门》 | 原作 10000 年附近 | 魂导器学习/制作/认证；按年代开放的魂灵研究与契约 |
| 斗三《龙王传说》 | 原作 20000 年附近 | 斗铠设计、材料、部件与实战加成；机甲执照、购置和能量 |
| 斗四《终极斗罗》 | 原作 30000 年附近 | 天罗星/天斗星生活、联邦客运、星舰指挥认证、参谋部述职、满月多模块入舰培训、能力证据分岗、舰员协同与损管、原文战舰分级、星际航行、行星探索与证据化军旅晋升 |

四代共享角色创建、自由行动、世界模拟和小说引擎，但人物、势力、地点、地图、技术与事件按时代隔离。旧时代人物不会因为缺少死亡年份而错误存活到后世；未成立组织、未开放地点和未出现技术会在规则层被拦截。

四个时代既可独立开局，也可在有效结算后沿同一存档按斗一→斗二→斗三→斗四继续。下一代继承的是需要核验的旧世档案、具名家庭旁支、声望与历史因果，不会无条件复制祖辈魂力、魂环、遗传能力或装备。每次跨时代生成带年份、来源、可信度和证据状态的可审查年表；推演假说明确标为非原著事实。旧机构必须先查旧世证据和当代权属，再缴费主张并参加听证；最多取得档案/名称沿革有限权利，经营必须另行投资成立当代新主体。

创建页和战斗状态使用原创四时代环境图，不含官方人物肖像、徽记或地图；视觉来源与非原著事实边界记录在 [`docs/visual-asset-provenance.md`](docs/visual-asset-provenance.md)。

## 当前已知问题

这个项目已经能运行，但“能运行”不等于“已经适合公开发布”。下面的问题目前仍然存在：

| 领域 | 当前问题 | 实际影响 |
|---|---|---|
| IP 与发行 | 尚未取得《斗罗大陆》相关著作权、商标或游戏改编授权 | 不能把“非商业同人”当成免责依据；不建议直接公开发行或商业化 |
| 原著核验 | 113 个结构化事件中已有 106 个章节顺序锚点，但并非所有人物、制度、地点和技术细节都已逐条核对 | 冷门人物、斗二与斗四传播制度、部分斗四军方称谓仍可能需要修正 |
| AI 文笔 | 真实模型四时代结构冒烟已完成，但长篇人物声音、重复率、节奏和连续多回合自然度仍未达到最终验收标准 | 同一模型在复杂行动中仍可能重述旧事、跳过行动或写出被审校拒绝的正文 |
| 自由行动覆盖 | 高频行动和主要成长路线已有专用结算，但玩家能想到的合法行动远多于现有路由 | 少数合理复杂行动仍可能被保守拒绝，或只能获得程序安全正文 |
| 四时代深度 | 四时代均有独立入口和专属系统，但内容密度并不完全相同 | 斗二至斗四的社会生活、地方支线和部分机构长期路线仍需继续补深 |
| 数值与局外成长 | 当前测试存档临时提供无限传承点，强遗物和高品质开局按同人爽点设计 | 抽取成本、保底节奏、遗物强度和长期周目收益尚不能代表最终平衡 |
| 模型依赖 | 正式自由行动需要外部模型接口 | 会产生 API 费用，并受供应商限流、断网、JSON 稳定性和模型版本变化影响 |
| 产品体验 | 当前是本地桌面网页原型，没有云同步、账号系统或多人玩法 | 移动端、无障碍、断网恢复、安装体验和跨设备存档仍需专项验收 |
| 仓库分支 | GitHub 默认分支 `main` 仍是早期设计文档版本，现役代码位于 `codex/iterative-optimization` | 公开前必须合并或切换默认分支，否则首页介绍和普通克隆都会指向旧版本 |

自动测试主要证明状态机、迁移、门禁和固定流程没有回归，不能证明所有原著细节都正确，也不能代替玩家对小说文笔的判断。更完整的验收边界见 [`docs/release-acceptance.md`](docs/release-acceptance.md)。

## 接下来准备做什么

### 近期：先把“像一部能玩的斗罗同人小说”做稳

- 继续用斗一至斗四原著材料核对人物阶段、事件顺序、制度、地点、技术和称谓，明确标注原著事实、原著归纳、游戏估算与同人原创。
- 扩充真实模型长局样本，重点处理人物声音趋同、旧事复述、行动被跳过、高潮节奏不足和连续场景重复。
- 为合理但仍会落入通用路由的自由行动补充原生结算，并让被拒绝的行动给出更准确的原因和替代路径。
- 重新平衡局外召唤、保底、强遗物、超限魂环与周目奖励，结束无限传承点测试状态。

### 中期：让世界比主线更有生活感

- 深化家庭、同辈、学院、宗门、职业、经营和地方势力的长期关系线，让普通生活也能持续改变人物。
- 丰富斗二至斗四的地方事件、机构生活和社会制度，缩小四时代之间的内容密度差距。
- 改进向量召回排序、人物长期记忆、章节节奏诊断和本轮召回可视化，减少“记得但没在正确场景想起”的问题。
- 完善新手引导、移动端布局、存档导入导出、错误恢复和低成本模型配置。

### 公开发布之前

- 先解决 IP 授权或把通用互动小说引擎与斗罗专属内容拆分，不能用一句免责声明替代权利许可。
- 完成全部 Git 历史的密钥、个人信息、原著文本、测试存档、模型输出和素材来源审计；轮换所有曾用于开发的 API Key。
- 明确代码许可证、同人内容边界、贡献规则、隐私说明和模型费用责任，再决定是否开放源码或仅发布可执行测试版。
- 完成真实玩家长局、窄屏、断网、限流、服务重启恢复和发行安全验收。

路线图表达的是开发方向，不代表对应功能已经完成，也不承诺具体发布日期。

## 公开与授权边界

仓库当前为 **Private**，并且没有开源许可证。即使代码中不包含原著全文，项目仍大量使用斗罗系列的名称、人物、势力、世界设定和事件结构，属于需要认真处理原作品权利的同人改编方向。

- 中国现行《著作权法》将改编权和信息网络传播权列为著作权人的权利；改编作品的作者可以拥有新增部分的权利，但行使时不得侵犯原作品著作权。非商业、注明原作者或写“仅供学习交流”并不会自动落入合理使用。
- GitHub 要求上传者确保自己有权公开相关内容；公开仓库会允许其他用户查看和 Fork，也可能面对版权或商标移除请求。
- 没有 `LICENSE` 意味着本仓库目前不是开源项目。它不会自动授予他人复制、分发、修改和再发布代码的通常开源权利，但 GitHub 平台条款仍允许公开仓库被查看和 Fork。

相关规则可查看[《中华人民共和国著作权法》](https://www.npc.gov.cn/c2/c30834/202011/t20201119_308796.html)、[GitHub 服务条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)、[GitHub 可接受使用政策](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies)和[仓库许可证说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。这段说明只用于披露项目状态，不构成法律意见；真正公开前应由熟悉中国游戏与著作权业务的律师审查。

## 已实现的核心能力

- 斗一使用 68 份精选身份与稳定家庭/住处档案；低稀有度只保留 4 个白色、6 个蓝色和 10 个紫色代表开局，高稀有度身份继续保留。旧存档与已经抽到的旧身世仍可加载和装备。
- 局外奇遇可指定系统流、签到、加点、人生模拟、证据任务或生态图鉴；指定后首名候选保证携带，觉醒即绑定，并在角色面板提供真实可用按钮。连续刷新会排除上一轮未锁定身份，减少开局重复。
- 局外召唤现有 213 种可抽武魂与 65 种可抽身世；“召唤记录 / 武魂仓库 / 身世仓库 / 遗物仓库”四个页签支持展开/收起、搜索与稀有度筛选。身世专属召唤仍每抽必得紫色以上，并保留金色10抽、红色30抽、七彩60抽独立保底。武魂和身世抽到后永久无限使用；已经抽到但退出新池的旧条目继续兼容。
- 三选一候选、无限重抽、自定义姓名、性格塑造、情境题、觉醒后人生目标。
- 299 个可觉醒武魂；机械生成的原创武魂由432个压缩为98个，其中白/蓝/紫只保留6/8/12个分类代表项。单、双生与三生武魂仍使用独立修炼和魂环账本。

## 生产模式

首次安装依赖后，可以构建前端和服务端并从单一端口启动：

```bash
npm install
npm run build
npm start
```

打开 `http://127.0.0.1:8787`。开发模式见前面的“开始游玩”，网页和规则服务默认使用 `5173` 与 `8787` 端口。

## 模型配置与隐私

在“模型设置”中填写 API Key、兼容接口地址和模型名。当前已重点验证 DeepSeek 兼容接口；其他兼容模型可以接入，但正文质量和 JSON 稳定性需要自行验收。密钥仅保存在本机 `.data/deepseek.json`，不会返回给网页端或写入 Git；DeepSeek 也可使用 `DEEPSEEK_API_KEY` 环境变量。

设置页同时显示本机模型调用次数、失败数、供应商返回的 token 数与累计延迟。遥测不保存 API Key、完整提示词、推理过程或生成正文。

没有配置模型时仍可创建和查看角色，但正式自由行动需要模型。模型不能决定成功率、胜负、魂力、物品、伤势、魂环或历史结果，也不能直接修改存档。

## 常见行动

- 通用：`冥想修炼`、`休息`、`找临时工作`、`查看地图`、`等待一年`
- 猎魂：`调查适合当前武魂的魂兽`、`购买猎魂补给`、`寻找足迹`、`观察弱点`
- 多人战斗：邀请有能力证据的岗位同伴；可先`与甲和乙共同训练生命防线连携`，或让三名互补岗位`共同训练攻守枢纽阵型`，再在战斗中准备并于有效回合内发动
- 关系与世界：`申请学院入学`、`拜师`、`加入势力`、`调查自己的身世`。成年伴侣、婚姻与家庭采用共同经历、双方明确同意、冷静期和现实准备的分阶段记录，不能用一句行动直接生成。
- 经济与运输：`调查本地市场行情和供需`、`承接药材运输合同`、抵达目的地后`交付运输合同货物`
- 身份与口碑：公开履约、重大事件和违法行为会经见证者延迟传播；`化名为青禾`与`恢复真名`保持地区身份分账
- 机构履历：领取专属事务后按任务页逐阶段行动并点击`推进阶段`，全部证据通过后才能最终交付和申请晋升
- 斗二：`学习魂导理论`、`收集魂导材料`、`制作魂导器`、`评估魂灵契合度`
- 斗三：`设计斗铠`、`打造斗铠部件`、`参加机甲模拟`、`申请机甲驾驶资质`
- 斗四：`向舰队参谋部述职`、`参加航线与指挥舰队培训`、`参加损管动力舰队培训`、`申请参谋部岗位评估`、`参加星舰指挥模拟`、`招募船员`、`申请项目舰船`、`前往森罗星`

斗四玩家项目舰按原文校正为陨星级侦察舰；龙王级护卫舰以上战区平台仍需现役舰队任务授权。

高速模式可以压缩叙事和长程修炼操作，但不改变基础成功概率。
