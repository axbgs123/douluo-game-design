# 未定之书

《斗罗大陆》斗一至斗四时代的本地单人互动小说 RPG。玩家从六岁武魂觉醒开始，用自由文本决定原创主角的行动。规则程序负责时间、成长、战斗、资源、关系与历史因果；DeepSeek 只负责理解复杂意图，并把已经确定的结果写成第三人称限知小说。

> 本项目是非商业同人原型，不包含原著全文。公开发行或商业化前必须另行确认 IP 授权。

## 当前可玩范围

新游戏可以独立选择四个时代：

| 时代 | 起始纪年 | 专属成长系统 |
|---|---:|---|
| 斗一《斗罗大陆》 | 原作 0 年附近 | 学院、宗门、猎魂、魂环与原作事件干预 |
| 斗二《绝世唐门》 | 原作 10000 年附近 | 魂导器学习/制作/认证；按年代开放的魂灵研究与契约 |
| 斗三《龙王传说》 | 原作 20000 年附近 | 斗铠设计、材料、部件与实战加成；机甲执照、购置和能量 |
| 斗四《终极斗罗》 | 原作 30000 年附近 | 星舰指挥认证、可信船员、舰船获取、星际航行与行星探索 |

四代共享角色创建、自由行动、世界模拟和小说引擎，但人物、势力、地点、地图、技术与事件按时代隔离。旧时代人物不会因为缺少死亡年份而错误存活到后世；未成立组织、未开放地点和未出现技术会在规则层被拦截。

## 已实现的核心能力

- 斗一拥有 36,000 个可复现出生组合；斗二至斗四拥有各自的时代出身、家庭气氛、地点与路线组合。
- 三选一候选、无限重抽、自定义姓名、性格塑造、情境题、觉醒后人生目标。
- 159 个可觉醒武魂；单、双生与三生武魂使用独立修炼和魂环账本。
- 时间、魂力、瓶颈、伤势、疲劳、金钱、负重、物品、债务、职业、犯罪与势力声望。
- NPC 在视野外移动、调整目标、建立关系，并保存对玩家的独立经历记忆。
- 原作事件按日期自行发展；只有可追溯到人物、势力或地点的玩家因果才可能改变关键节点。
- 猎魂八阶段与程序战斗：需求、调查、准备、旅行、追踪、战斗、吸收、后果。
- 观察、防守、距离、技能、撤退、伤势、死亡、有限条件复生和周目结算。
- 地图连接、时代地图过滤、任务、承诺、线索、计划、悬赏、世界消息和自定义标点。
- 常驻“时代”面板提供四代专属状态、年代门槛和直接操作按钮，不要求玩家猜测自由文本关键词。
- SQLite 自动存档、动作幂等、版本冲突保护、动作收据和检查点回溯。
- 四时代共 4,000 条同人叙事规则，按行动、地点和年份检索，不把整份规则塞入上下文。
- 隐藏身份、远方事件与角色未知情报不会提前发送给网页或模型。
- AI 正文经过第三人称、年代、知识边界、文风与篇幅审校；失败不会篡改已确定的规则结果。

## 本地运行

需要 Node.js 24 或更高版本。

```bash
npm install
npm run build
npm start
```

打开 `http://127.0.0.1:8787`。开发模式使用 `npm run dev`，网页和规则服务默认位于 `5173` 与 `8787` 端口。

## DeepSeek

在“模型设置”中填写 API Key、兼容接口地址和模型名。密钥仅保存在本机 `.data/deepseek.json`，不会返回给网页端或写入 Git；也可使用 `DEEPSEEK_API_KEY` 环境变量。

没有配置模型时仍可创建和查看角色，但正式自由行动需要模型。模型不能决定成功率、胜负、魂力、物品、伤势、魂环或历史结果，也不能直接修改存档。

## 常见行动

- 通用：`冥想修炼`、`休息`、`找临时工作`、`查看地图`、`等待一年`
- 猎魂：`调查适合当前武魂的魂兽`、`购买猎魂补给`、`寻找足迹`、`观察弱点`
- 关系与世界：`申请学院入学`、`拜师`、`加入势力`、`调查自己的身世`
- 斗二：`学习魂导理论`、`收集魂导材料`、`制作魂导器`、`评估魂灵契合度`
- 斗三：`设计斗铠`、`打造斗铠部件`、`参加机甲模拟`、`申请机甲执照`
- 斗四：`参加星舰指挥模拟`、`招募船员`、`申请项目舰船`、`前往森罗星`

高速模式可以压缩叙事和长程修炼操作，但不改变基础成功概率。
