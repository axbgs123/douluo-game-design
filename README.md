# 未定之书

《斗罗大陆》斗一至斗四时代的本地单人互动小说 RPG。玩家从六岁武魂觉醒开始，用自由文本决定原创主角的行动。规则程序负责时间、成长、战斗、资源、关系与历史因果；DeepSeek 只负责理解复杂意图，并把已经确定的结果写成第三人称限知小说。

每次调用叙事模型前，程序会先编译并审计 `narrative-logic.v1` 逻辑合同：锁定原著年代与地点、主角欲望、人物知情来源、制度权限、可用资源、在场人物反应义务、固定程序后果和必须留下的状态变化。逻辑包失败时不会调用模型，也不会用重复生成掩盖确定性缺口。

长篇记忆使用 SQLite 本地向量库：每次已提交行动自动写入章节索引和场景索引，生成前先选择最多 3 个相关章节，再从这些章节中召回最多 8 条具体旧事，不再依赖无限扩张的聊天上下文。实现与信息边界见 [`docs/vector-memory.md`](docs/vector-memory.md)。

每个成功回合还会在 `scene_archives` 只追加保存完整正文、玩家输入、程序固定结果、章节归属、版本和 SHA-256；正文重写新增版本而不覆盖旧稿。`turn_trace_groups / turn_trace_attempts` 保存不含 API Key 的冻结存档、完整模型请求与返回、每次审校问题和最终采用稿。设置页可查看召回片段、相似度、来源与入选理由，并可只读重放审校或用原始提示词重新调用模型比较，重放不会推进存档。

正文不是先自由生成再只靠审校纠错。每次调用前的 `narrative-logic.v1` 现在包含正向 `generationContract`：明确场景目标、四个必写节拍、允许事实白名单、禁止声明、时代语言和停笔边界。私下隐藏武魂场景会在生成前清空NPC参与者与见证者，只允许写已结算的显形、感知、消耗和主动收回。

Schema 46进一步把事实记忆收回程序：模型只能建议章节名，不能写入摘要、未决事项、关键选择或NPC笔记；长期摘要、NPC记忆、章节向量和行动向量只从结构化状态、任务与程序行动收据重建。AI选项展示前会用克隆存档预跑完整规则，未匹配专用结算的事实型行动不会交给小说模型补造结果。原著专属能力与人物接触需要明确所有权、知情来源、同地或旅行证据。

Schema 47继续修正程序自己提供给模型的开局底稿：先天满魂力只复测一次；宗门内部场景不再凭空出现“无关人员”和匿名记录员；任务、人生目标与卷目标改为人物能当场理解的具体人、地点、帮助与条件。斗一保留六颗黑石和水晶球，斗三改用初等学院觉醒室纹路，斗四改用六边形觉醒室与魂力测试仪；旧存档当前正文与相关目标会同步迁移，无损历史版本保持不动。

斗罗结构化知识使用独立向量层，按当前时代和玩家已知范围召回人物性格、人生阶段、关键关系、势力利益、地点、重要事件与魂兽生态。人物只注入当前阶段的公开姓名、目标、势力和已证实力，不再把最终称号、全部武魂、终身目标与后来关系塞给开局模型；玩家未知的秘密旧事和未来事件标题也不会进入正文请求。地点与势力携带“原著 / 原著归纳 / 原创”来源。详见 [`docs/canon-knowledge-vector.md`](docs/canon-knowledge-vector.md)。

当前160名结构化原著人物已全部使用人工分段人生卡，共229个时间切片；低重要度人物也不再依赖终身目标兜底。四大单属性宗族、南秋秋、叶骨衣等按实际阶段切换公开势力；白秀秀龙族潜伏身份列为隐藏卡，不会向早期生成泄露。阶段目标不用否定句暗示未来；人物实力向量和人物页也不会泄露隐藏身份、秘密伤势、精确底牌、伪装动机、内部目标或神位进度。

世界基本逻辑使用第三个独立向量层：高天赋会触发震惊、复测、收徒竞争、资源倾斜、监视和敌对威胁，但不保证无条件送宝、拜师成功或私人好感；暗杀必须经过可靠消息、威胁评估、监视试探和行动条件成立后才可能升级。
设计说明见 [`docs/world-logic-vectors.md`](docs/world-logic-vectors.md)。

剧情导演2.0把主线相关行动组织成“立局—主动推进—阻力显形—局势扩大—阶段兑现—不可逆转折”六阶段。每阶段都有证据门槛，地方支线不会替主线刷进度；导师、名额、食宿、训练、身份和第一里程碑使用兑现账本，NPC会依据职责与利益主动要求玩家回应，但不会替玩家答应。四时代开局条件分别服从当代原著制度。详见 [`docs/story-director.md`](docs/story-director.md)。

具名NPC使用欲望—责任—信息—权限—资源行动规划器，按自身目标执行训练、调查、保护、组织事务与对抗计划；没有路线、许可和资源时会受阻。每人还根据年龄、职业、当前势力和稳定气质维护日常义务、注意焦点、说话节奏和拒绝边界；一个计划按“日常核对—执行—复盘—验证”四拍推进，不会只等玩家触发或重复同一句话。详见 [`docs/npc-planner.md`](docs/npc-planner.md)。

地方事件拥有专属默认结局与持续后果：错过采药队、魂兽越界、商路扣押、学院争议等事件会改变供需、治安、关系、势力、生态和后续任务，而不是统一“自行收场”。详见 [`docs/event-consequences.md`](docs/event-consequences.md)。

> 本项目是非商业同人原型，不包含原著全文。公开发行或商业化前必须另行确认 IP 授权。

## 当前可玩范围

新游戏可以独立选择四个时代：

| 时代 | 起始纪年 | 专属成长系统 |
|---|---:|---|
| 斗一《斗罗大陆》 | 原作 0 年附近 | 学院、宗门、猎魂、魂环与原作事件干预 |
| 斗二《绝世唐门》 | 原作 10000 年附近 | 魂导器学习/制作/认证；按年代开放的魂灵研究与契约 |
| 斗三《龙王传说》 | 原作 20000 年附近 | 斗铠设计、材料、部件与实战加成；机甲执照、购置和能量 |
| 斗四《终极斗罗》 | 原作 30000 年附近 | 天罗星/天斗星生活、联邦客运、星舰指挥认证、参谋部述职、满月多模块入舰培训、能力证据分岗、舰员协同与损管、原文战舰分级、星际航行、行星探索与证据化军旅晋升 |

四代共享角色创建、自由行动、世界模拟和小说引擎，但人物、势力、地点、地图、技术与事件按时代隔离。旧时代人物不会因为缺少死亡年份而错误存活到后世；未成立组织、未开放地点和未出现技术会在规则层被拦截。

四个时代既可独立开局，也可在有效结算后沿同一存档按斗一→斗二→斗三→斗四继续。下一代继承的是需要核验的旧世档案、具名家庭旁支、声望与历史因果，不会无条件复制祖辈魂力、魂环、遗传能力或装备。每次跨时代生成带年份、来源、可信度和证据状态的可审查年表；推演假说明确标为非原著事实。旧机构必须先查旧世证据和当代权属，再缴费主张并参加听证；最多取得档案/名称沿革有限权利，经营必须另行投资成立当代新主体。

创建页和战斗状态使用原创四时代环境图，不含官方人物肖像、徽记或地图；视觉来源与非原著事实边界记录在 [`docs/visual-asset-provenance.md`](docs/visual-asset-provenance.md)。

## 已实现的核心能力

- 斗一使用 80 份精选身份与稳定家庭/住处档案；低稀有度只保留 4 个白色、6 个蓝色和 10 个紫色代表开局，高稀有度身份继续保留。旧存档与已经抽到的旧身世仍可加载和装备。
- 局外奇遇可指定系统流、签到、加点、人生模拟、证据任务或生态图鉴；指定后首名候选保证携带，觉醒即绑定，并在角色面板提供真实可用按钮。连续刷新会排除上一轮未锁定身份，减少开局重复。
- 局外召唤现有 213 种可抽武魂与 65 种可抽身世；“召唤记录 / 武魂仓库 / 身世仓库 / 遗物仓库”四个页签支持展开/收起、搜索与稀有度筛选。身世专属召唤仍每抽必得紫色以上，并保留金色10抽、红色30抽、七彩60抽独立保底。武魂和身世抽到后永久无限使用；已经抽到但退出新池的旧条目继续兼容。
- 三选一候选、无限重抽、自定义姓名、性格塑造、情境题、觉醒后人生目标。
- 299 个可觉醒武魂；机械生成的原创武魂由432个压缩为98个，其中白/蓝/紫只保留6/8/12个分类代表项。单、双生与三生武魂仍使用独立修炼和魂环账本。
- 开局按“身份 × 武魂类别 × 主持机构”生成：器、兽、本体、植物、食物和元素武魂使用不同显形与测试动作；平民、宗门、贵族、无身份穿越者和魂兽养育者拥有不同现实目标。宗门少主不会重复选择加入本宗，斗二至斗四公共觉醒也不再套用斗一武魂殿执事。
- 时间、魂力、瓶颈、伤势、疲劳、金钱、负重、物品、债务、职业、犯罪与势力声望。
- NPC 在视野外移动、调整目标、建立关系，并保存对玩家的独立经历记忆。公开事件先形成地方口碑，再依时代进入不同传播链：斗一只使用地方告示、口耳传闻、商旅消息与势力通告，不生成记者、责任编辑、媒体竞争或媒体联盟；后世现有报刊、魂导传媒或联邦信息网玩法仍须逐时代接受原著核验。后世媒体机构拥有不同选稿立场和独立责任编辑；玩家可访谈署名编辑、完成独立调查并补交材料，但采访本身不能改稿。原创核验、明确标注的转载和证据更正会长期改变机构信誉及签发编辑的来源信任；跨机构共同核验仍受独立签字、有限资源、议题排期、准入、退出、修复和更正责任约束。
- “手记”页可统一搜索角色已经知道的情报、新闻、任务、关系、未解线索和关键选择；检索只读取公开视图，不会泄露隐藏身份、未来事件或未取得的原著知识。外部项目对标和许可证边界记录在 [`docs/external-benchmark.md`](docs/external-benchmark.md)。
- 日常工作按年龄、岗位、地点、时代、职业熟练度与难度结算；危险童工会被拒绝，雇主验收、收入、采购、存取款、借贷和经营投入均保留流水。
- 药材、金属、粮食、魂导材料和日用品拥有分地点供需与价格指数；本地事件会扰乱运输，采购和商铺经营按实际行情形成进货、回款与盈亏。
- 原作事件按日期自行发展；只有可追溯到人物、势力或地点的玩家因果才可能改变关键节点。
- 当前有113个去重后的结构化原著事件和92条分类关系，其中67条属于真正硬前置，其余为催化、并列结果或观察路线。106个节点已有本地原文章节顺序锚点；其余7个正篇前历史、跨年归纳或证据不足节点已显式标记未核实原因，不伪造章节。前置被玩家延后、替代或取消后，依赖它的后继会等待或重新推演；分支同时留下人物目标、地方制度/供需和直接后继节点记录，不再只改一个偏差数字。
- 猎魂八阶段与程序战斗：需求、调查、准备、旅行、追踪、战斗、吸收、后果。
- 可信且同地的同行者可按强攻、防护、控制、治疗、侦察或协同分工；岗位需要能力证据，并分别影响输出、承伤、控制、恢复与追踪。固定双人连携、三岗位阵型，以及强攻/防护/控制/治疗或侦察组成的四人编队可跨战斗积累熟练度；疲劳失误留下复盘记录，达标后解锁战术分支。三人和四人阵型必须由同一组成员训练到各自最低熟练度，并按实际参与人数独立结算协同消耗与冷却。
- 观察、防守、距离、技能、撤退、伤势、死亡、有限条件复生和周目结算。
- 地图连接、时代地图过滤、任务、承诺、线索、计划、悬赏、世界消息和自定义标点。
- 常驻“时代”面板提供四代专属状态、年代门槛和直接操作按钮，不要求玩家猜测自由文本关键词。
- 在册学院、宗门、协会与军方身份拥有机构事务、贡献、验收和晋升履历；通用宗门事务会按武魂能力或玩家明确选择进入外勤、情报、支援分支。七宝琉璃宗、昊天宗、象甲宗、唐门、本体宗及后世主要机构拥有立场不同的具名复核人；玩家可当面询问异议，但谈话不能代替行动，失败推进会降低信任，合格收据才能恢复关系并通过验收。
- SQLite 自动存档、动作幂等、版本冲突保护、动作收据和检查点回溯。
- 四时代共 4,000 条同人叙事规则，按行动、地点和年份检索，不把整份规则塞入上下文。
- 隐藏身份、远方事件与角色未知情报不会提前发送给网页或模型。
- AI 正文经过第三人称、年代、知识边界、文风与篇幅审校；失败不会篡改已确定的规则结果。前台默认是代入式成长小说，只有玩家明确调查秘密、证据、失踪或阴谋时才进入解密结构。斗一至斗四分别拥有生活质感配置，研究见 [`docs/research/douluo-original-prose-study.md`](docs/research/douluo-original-prose-study.md)。
- 推荐选项按中国男频互动网文的“成长/资源、关系/势力、秘密/风险”三轴生成；程序情境选项优先，泛化占位、陌生原著人物直达与隐藏武魂泄露会被过滤。相关原著和同人机制研究见 [`docs/research/douluo-choice-and-plot-logic.md`](docs/research/douluo-choice-and-plot-logic.md)。

## 本地运行

需要 Node.js 24 或更高版本。

```bash
npm install
npm run build
npm start
```

打开 `http://127.0.0.1:8787`。开发模式使用 `npm run dev`，网页和规则服务默认位于 `5173` 与 `8787` 端口。

## DeepSeek

在“模型设置”中填写 API Key、兼容接口地址和模型名。密钥仅保存在本机 `.data/deepseek.json`，不会返回给网页端或写入 Git；也可使用 `DEEPSEEK_API_KEY` 环境变量。

设置页同时显示本机模型调用次数、失败数、供应商返回的 token 数与累计延迟。遥测不保存 API Key、完整提示词、推理过程或生成正文。

没有配置模型时仍可创建和查看角色，但正式自由行动需要模型。模型不能决定成功率、胜负、魂力、物品、伤势、魂环或历史结果，也不能直接修改存档。

## 常见行动

- 通用：`冥想修炼`、`休息`、`找临时工作`、`查看地图`、`等待一年`
- 猎魂：`调查适合当前武魂的魂兽`、`购买猎魂补给`、`寻找足迹`、`观察弱点`
- 多人战斗：邀请有能力证据的岗位同伴；可先`与甲和乙共同训练生命防线连携`，或让三名互补岗位`共同训练攻守枢纽阵型`，再在战斗中准备并于有效回合内发动
- 关系与世界：`申请学院入学`、`拜师`、`加入势力`、`调查自己的身世`。成年伴侣、婚姻与家庭采用共同经历、双方明确同意、冷静期和现实准备的分阶段记录，不能用一句行动直接生成。
- 经济与运输：`调查本地市场行情和供需`、`承接药材运输合同`、抵达目的地后`交付运输合同货物`
- 身份与口碑：公开履约、重大事件和违法行为会经见证者延迟传播；`化名为青禾`与`恢复真名`保持地区身份分账
- 机构履历：领取专属事务后按任务页逐阶段行动并点击`推进阶段`，全部证据通过后才能最终交付和申请晋升
- 斗二：`学习魂导理论`、`收集魂导材料`、`制作魂导器`、`评估魂灵契合度`
- 斗三：`设计斗铠`、`打造斗铠部件`、`参加机甲模拟`、`申请机甲驾驶资质`
- 斗四：`向舰队参谋部述职`、`参加航线与指挥舰队培训`、`参加损管动力舰队培训`、`申请参谋部岗位评估`、`参加星舰指挥模拟`、`招募船员`、`申请项目舰船`、`前往森罗星`

斗四玩家项目舰按原文校正为陨星级侦察舰；龙王级护卫舰以上战区平台仍需现役舰队任务授权。

高速模式可以压缩叙事和长程修炼操作，但不改变基础成功概率。
