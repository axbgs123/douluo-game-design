# 原著还原生成层审查（2026-08-26）

## 范围

本轮从行动原话开始，检查行动语义整理、程序路由、生成前场景合同、场景知识、原著/记忆/世界逻辑召回、人物资料、故事卷、模型正文、AI选项、AI记忆回写与生成后审校。审查使用本地斗一至斗四文本作证据，只保存结构化结论，不复制原著正文。

## 审查时确认的P0问题

1. 模型可把无程序依据的摘要、未决事项、关键选择与NPC笔记直接写回存档，并进入后续向量召回。
2. AI选项不保证存在专用规则路由；事实型选项落入“一般行动”后，模型可能替程序补造测试、人物、资源或培养结果。
3. 私密场景虽然清空了逻辑包参与者，模型请求仍包含会议事件、故事卷待回应NPC、关系、NPC记忆与近期会议正文。
4. 斗一规则库可随机抽到“魂导通信”等后世内容；斗二、斗三也存在相同的跨时代规则污染风险。
5. 无能力所有权证据的角色可以直接输入玄天功、紫极魔瞳等原著专属能力；普通本地角色也可凭读者输入的名字打听尚未认识的原著人物。
6. 生成白名单允许当前真实库存与武魂描述，但旧审校会把已持有的养剑木匣和已声明的无锋剑胚误判为幻觉。
7. 完整角色对象把“七彩、神话”等局外抽取等级直接发送给小说模型，可能形成原著不存在的公开武魂品质体系。
8. 斗一无条件禁用“识海”会误伤明确拥有前世异界修行记忆的出身；边界应是“不可冒充斗罗公共体系”，不是禁止主角回忆前世词汇。

## 已完成修复

- Schema 46从程序行动账本、任务与公开武魂重建长期事实；清空模型生成的摘要、未决事项、选择与NPC笔记，移除来源为“叙事提取”的NPC记忆。
- 模型现在只能建议章节名，不能维护事实记忆。场景无损档案与回合轨迹继续保留原始模型输出供审查，但不进入事实召回。
- 行动向量仅保存玩家行动与程序结果，不再保存AI正文；回溯会删除未来分支向量，章节摘要也按程序账本重建。
- AI选项在展示前使用克隆存档预跑完整规则；被阻止、无法完成或需要产生事实却落入“一般行动”的选项不会显示。正文重写后的选项执行同一门禁。
- 未匹配专用结算的事实型自由行动直接返回无法完成，不再调用小说模型补结果。
- 原著专属能力需要魂环、特殊体系、已确认情报或行动账本中的学习证据；知道名字不等于掌握。
- 未认识的原著人物需要亲历、关系、情报或明确穿越记忆来源；异地人物还必须先完成旅行。
- 私密场景从模型请求中移除关系、任务、故事卷、待回应NPC、NPC记忆、新闻、人物档案、地方后果与近期正文；场景知识只保留当前地点和行动明确提及的已知情报，世界逻辑只保留秘密、知情和无目击规则。
- 生成角色视图移除出身稀有度、武魂颜色品质、来源年代和适配评分；隐藏武魂只标“仅主角知道”。
- 斗一至斗三的运行时规则检索过滤后世技术，取消信息传播与原著替位章节的默认轮换。30个行动序号乘九类代表行动静态扫描未再检出对应后世规则。
- 斗二文风卡按年份区分魂灵制度形成前后；斗一异世修行出身只允许在主角内心把识海当作前世概念，不允许本地NPC或制度使用。
- 人物生成上下文只使用前两个稳定气质锚点，不把完整终身性格当作早期人格；关系、责任和当前目标继续服从阶段状态。
- 精确未来事件标题在其年份前出现时会被时间线审校拒绝。
