# 遗物原著逻辑重做（已由全文事实核查后的实现替代）

日期：2026-08-28

> 后续原著全文核查确认：本文件中的“魂斗罗护环契”与斗一吸收规则冲突，其他多项契约/药匣也未找到原文实体依据。冲突机制和未证新池条目均已替换；最终实现与来源分层见 `heirloom-original-text-factcheck-2026-08-28.md`。

## 原著锚点

- 斗罗世界的超常成长来自武魂、魂环、魂骨、魂技、高阶魂师护法、拟态修炼环境、学院/宗门资源和真实财富。
- 高阶资源必须有持有人、权限、到场条件、使用痕迹与暴露风险。
- 关系来自共同经历和利益，信物不能强制好感；魂环承载取决于身体，外部护法不能把真实上限凭空翻倍。

## 断裂因果与修复

| 严重度 | 旧问题 | 最小修复 |
|---|---|---|
| 高 | 商路信牌完成一次询价便凭空产生300金魂币 | 改为商会预存金牌，三次从已有余额各兑付100并写经济流水 |
| 高 | 无署名荐书直接增加信任 | 改为具名引荐函，只保证正式面谈/试学，不增加信任或保证录取 |
| 高 | 魂环量尺把身体承载上限提高150% | 改为魂斗罗护环契；护法者必须召请、到场并登记，只提高成功率、压低失败伤害 |
| 高 | 因果残线恢复钱物和身体，等同回档 | 改为防御型外附魂骨，只挡一次非死亡重创的身体后果，钱物与胜负不回滚，并增加暴露风险 |
| 高 | 岁月锚钉直接压缩真实时间 | 改为万年头部魂骨凝神技，真实时间不变，只强化五次有效学习 |
| 中 | 温魂灯芯瞬间满状态 | 改为战地治疗药匣，脱战后耗时两小时治疗，不能救必死伤 |
| 中 | 星痕罗盘无视路程 | 改为飞行魂师护送契，要求已调查航线、护送者到场，不能穿越封锁 |
| 中 | 百炼炉心凭空变出材料 | 改为已经随身携带的庚辛城备用材料匣，失败后开封实物 |

## 修订后反应链

`玩家携带资源 → 满足地点/目标/见证/脱战等条件 → 具体人员或物资到场 → 发动并扣次数 → 账本记录收益 → 魂骨或高价值契约可能增加暴露与觊觎`

遗物保持金手指级玩法价值，但不再建立第二套超出斗罗底层规则的因果、时间或好感系统。
