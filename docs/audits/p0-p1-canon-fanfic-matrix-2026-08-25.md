# P0—P1 原著与同人前后对照矩阵

本文件是本轮开发硬门禁。每项先记录“实现前原著锚点 / 同人样本启示 / 禁止照搬”，实现后再补代码、测试、页面与二次对照证据。原著只提炼机制，不复制正文；同人只使用公开作品页、简介与目录，不把同人设定写成原著事实。

## 对照来源

原著本地核对：

- 斗一：圣魂村工读名额、诺丁学院注册、宿舍、同伴冲突、拜师与第一次猎魂段落。
- 斗二：史莱克新生报名、学费、宿舍、班主任、新生考核与淘汰压力段落。
- 斗三：红山学院魂师班、家庭生活、班主任利益、同龄冲突、推荐信与东海学院报到段落。
- 斗四：天罗初等魂师学院紫萝城分院报名、正副班主任、体能记录、班级实战与私人导师段落。

公开同人样本：

- [《斗罗：与三哥同窗的岁月》](https://fanqienovel.com/page/7607847844057205785)：公开目录将村庄、诺丁新生、导师理论、猎魂森林和第一魂环组成连续早期成长段。
- [《我在斗罗训练宝可梦》](https://fanqienovel.com/page/7534333826948926489)：公开目录把第一魂环、毕业、皇家学院、选拔赛和争队长连续安排，说明学院身份需要后续竞争兑现。
- [《斗罗之时光蝶愿》](https://fanqienovel.com/page/7487236631578037273)：公开目录含七舍成员、大师青睐、史莱克拒收与极限训练；“重要人物青睐”是常见爽点，也最容易写成无条件送机缘。
- [《斗罗：无双剑匣，石珠镇世》](https://fanqienovel.com/page/7612904989945515070)：公开目录用较多篇幅铺觉醒前生活、觉醒反应和学院规则，说明强武魂仍需持续场景兑现。
- [《斗罗：混沌青莲，神级武魂白虎》](https://fanqienovel.com/page/7538826046607477822)：皇室身份与皇家学院并存，说明贵族开局不等于只能留在家族教师路线。

## 完成判据

每一行只有同时具备以下证据才可从“待实现后补”改为“通过”：

1. 持久结构化状态，而非只写提示词。
2. 成功、失败、拒绝、撤回或资源不足的规则结算。
3. 三轴选项和自然语言路由测试。
4. 至少一条真实浏览器流程。
5. 实现后重新对照原著年代边界与公开同人读者承诺，并记录保留与拒绝的机制。
