# 四时代制度模板词专项审计

审计日期：2026-08-26。

本轮针对用户指出的“点名”类问题，检查前台正文、规则回执、推荐选项、学院状态、觉醒场景和模型前置世界逻辑。目标不是机械禁词，而是避免把一个时代或现实学校的整套制度复制到四个时代。

## 原著前置核对

用户提供的斗一至斗四本地文本只用于只读核查，不进入仓库。相关语境确认如下：

- 斗一“点名”命中实际是“有点名声”，“签到”命中实际来自“抽签到”，都不是学校制度；早期学院相关语境没有形成“班主任—课表—学籍—首月考核—结业”链。普通初级学院应围绕觉醒证明、地方工读证明、学院老师、宿舍、课程、工读劳动和第一魂环展开。
- 斗二可证班主任、报到、宿舍和新生考核；新生考核不能被压成四时代统一的首月考试。
- 斗三可证班主任、义务教育、魂师班、分班与班级实战；适龄基础教育测试用于了解基础或安排班级，不能被普通低分自动改成付费淘汰。
- 斗四可证正副班主任、课程表、体能记录和班级实战；这些后世学校词不能倒灌斗一。
- “复核”“核验”可以用于内部规则、后世媒体、工程、军籍或档案场景，但不能成为任何人物处理任何事情的万能前台动词。

## 修复结果

| 修复前断裂 | 修复后状态 |
|---|---|
| `AcademyLifeView`统一使用报到安置、基础课程、首月实战考核、首月结业 | Schema 45改为中性状态码：入学安顿、共同学习、同辈磨合、阶段考核、阶段完成；同时保存分时代教师职务、生活安排、考核名和完成名 |
| 斗一普通学院一律提交材料、参加入学考试、领取课表、找班主任 | 斗一普通学院凭觉醒证明/工读证明与来处说明进入，不虚构统一入学考试；前台使用学院老师、宿舍、教室、工读安排和基础课程与实战检查，检查结果不显示统一百分制月考分数 |
| 斗三义务教育可能因统一分数线拒收 | 公共义务教育测试只决定班级与课程起点，不因一次低分剥夺适龄基础教育 |
| “等主持者叫到名字”“请主持者” | 改成负责本次觉醒的具体魂师示意入阵，后续选项直接使用存档中的具名职务或姓名 |
| 高天赋反应写成复核、资源额度、培养表 | 改成换水晶重测、请能作主的人到场、哪位老师愿意教、训练场能用多久、谁承担食宿和第一次猎魂帮助 |
| 猎魂使用责任页、签字栏 | 内部仍保存责任边界，前台改成具体人物当面说清花费、同行、手令和撤退条件 |
| 正文可能出现“主角”“玩家”“系统替他们宣布关系” | 小说审校新增后台称谓污染门禁；规则替身也会先清洗这些词 |
| 力、御、敏、破四族觉醒上下文都指向`min-clan` | 分别修正为`strength-clan`、`defense-clan`、`speed-clan`、`breaking-clan`，并迁移旧存档错误归属 |
| 学院老师成为导师后会被存档规范化重新覆盖成学院职务 | 师徒关系优先于学院职务，重复加载不会破坏已经成立的师徒状态 |

## 自动门禁

- 斗一学院时代档案不得含“班主任、课表、学籍、首月、结业”。
- 四个单属性宗族的觉醒上下文必须各自使用正确势力 ID。
- 小说正文出现“玩家、主角、程序判定、固定结果、规则包、小说引擎、系统替”等后台称谓时必须重写。
- Schema 44旧学院状态会迁移到Schema 45的分时代状态，并清理旧前台模板词。
- Playwright实际走通斗一普通学院来处证明—学院生活—阶段检查—导师试学—拜师—导师课程—首环帮助路线。

## 保留边界

地图“标点”指玩家自建地图标记，与学校点名无关，继续保留。斗三、斗四的媒体、工程、升灵台、军籍与舰队流程仍可使用符合当代机构的核验、登记和述职，但必须由对应职业人物说出，不能反向污染斗一生活场景。
