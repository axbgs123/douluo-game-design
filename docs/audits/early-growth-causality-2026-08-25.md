# 觉醒后早期成长因果审计

## 原著锚点

- 六岁孩子的学院选择受觉醒档案、监护、地方名额、费用、路程和学院考核约束。
- 重要学院拥有自己的选拔门槛，不能与普通初级学院共用“一句报名即录取”。
- 强者或普通魂师都不会因为玩家输入“拜师”便自动承担长期授业责任；至少要有接触机会、方向适配、试学证据和双方确认。
- 第一魂环需要情报来源、物资、可靠成年魂师、路线和受管控猎魂区的进入凭证。

## 断裂因果与最小修复

| 严重度 | 旧断裂 | 缺失环节 | 当前修复 |
| --- | --- | --- | --- |
| 高 | 有魂力即可四小时直接入学 | 监护、材料、费用、考核、报到 | `academyApplication` 持久保存条件核对、材料准备、入学考核、待报到与已入学 |
| 高 | “寻找导师”会生成散修并立即收徒 | 身份来源、动机、能力评估、试学和明确同意 | `mentorPursuit` 持久保存候选来源、资历、动机、两次试学与最终决定 |
| 高 | 钱不足仍会获得猎魂补给 | 商铺价格与真实支付 | 余额不足直接阻止，物品不进入背包 |
| 高 | 六岁角色凭两项准备独自出发 | 成年责任人和入林权限 | 十二岁以下必须有同地可信成年魂师；猎魂森林另需实名担责的入林凭证 |
| 中 | 推荐来源取任意第一段关系 | 推荐者知识与资格 | 优先选择导师、执事、猎人、学院或宗门来源，否则标为地方档案与向导交叉记录 |

## 修订后反应链

```text
觉醒结果
→ 玩家申请学院或寻找导师
→ 机构/候选人核验公开资料与责任边界
→ 玩家准备材料、参加考核或完成试学
→ 失败保留记录，成功只获得下一阶段资格
→ 玩家与监护人/导师再次确认
→ 学员或师徒身份正式写入关系与任务
→ 第一魂环再核对钱、同行者、凭证、路线和目标
```

## 选项约束

- 成长/资源：提交报名材料、参加考核、完成试学、购买补给。
- 关系/势力：请监护人签字、与导师谈授业责任、请有权限者实名担保。
- 秘密/风险：保留隐藏武魂、放弃不合适的录取或导师、推迟高风险猎魂。
- 每项必须是当前可执行动作，不承诺录取、收徒或安全归来。

这些状态会进入生成前场景卡、逻辑合同和正文模型上下文。AI在“待考核”“试学考察”等阶段不得把下一阶段写成已经发生。
