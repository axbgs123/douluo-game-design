# 原著因果与时间推进复查

日期：2026-08-25

## 复现问题

1. 长时间快进先把NPC更新到终点年份，再处理期间的早期事件和自主行动。
2. 任意人物因果都会令姓名、目标和势力阶段永久停止校正。内存复现中，与唐三普通接触一次后，六年后的目标仍停在诺丁学院。
3. 对话在行动规则和提交阶段重复记账。八次交谈形成16条历史足迹，总强度40。
4. 分支传播设置了不低于事件惯性门槛的强度下限。一次诺丁学院强影响快进斗一后形成47个替代节点。
5. 原著事件虽然被延后或替代，关系基线和实力快照仍可能按旧日期自动写入。
6. 认识一个参与者会直接暴露其远方动态事件和已发生秘密事件。
7. 模型因果包携带内部人物ID，可能把“雪清河”反向泄漏为`qian-renxue`。

## 修复

- 时间按年界、三十日周期、原著事件日和延后复核日依次推进，不再用终点年份状态处理过去。
- 因果拆为身份、目标、势力、关系、实力、地点、生死、资源和制度九个领域；旧存档由来源与描述保守推断。
- 每条因果保存有效期和传播深度；同动作重复记录合并，多条记录递减叠加。
- 普通交谈只更新关系、记忆和世界偏差，不进入历史级因果账本。
- 分支传播每跳保留45%强度，并受三年、共同参与者、短期同地点和势力领域门槛限制，不再设置保证触发下一节点的强度下限。
- 延后节点最多复核两次；每次按新日期重新检查参与者、领域和有效强度，之后发生、替代或取消。
- 被抑制的相识事件不会按旧日期建立关系；实力路线被改变后改走程序成长，不再套用未来原著等级。
- 人物姓名始终按公开人生阶段推进；目标与势力只由对应领域的有效因果覆盖。
- 动态事件和原著事件只有本地、公开消息或可靠事件情报才能进入场景知识；认识参与者本身不是消息来源。
- 模型因果包改为当前公开人名、势力名和地点名，不发送内部人物ID。

## 复验

- 一次普通交谈产生0条历史级因果。
- 轻微关系接触后，唐三六年后的目标正常进入史莱克阶段。
- 改变拜师前提后，师徒关系不会在旧日期强行建立。
- 改变修炼路线后，唐三不会在八年节点自动套用四十级快照。
- 认识唐三但没有来信、传闻或情报时，远方事件不进入场景知识。
- 相同的诺丁学院强影响快进斗一全程，只形成入学与拜师两个直接相邻分支；原复现为47个。

## 剩余边界

现有107个事件仍主要依靠结构化参与者、势力、地点和时间邻接推断依赖。关键事件若需要更精确地区分“必要角色、可替补角色、必要资源、必要制度”，应逐事件增加显式前提，但不得重新使用共享主角或共享势力作为无限传播捷径。
