# 原著时间线提前泄漏审计

日期：2026-08-25

范围：人物状态、人物向量、势力归属、关系向量、历史事件、NPC规划、场景知识、模型输入与旧存档迁移。

## 根因

此前程序虽然会按日期触发原著事件，却同时把人物的终身资料放进当前上下文：

1. 人物核心向量一次写入全部别名、最终武魂、全部势力和终身目标。
2. `WorldNpcState.currentGoal`直接采用人物定义中的长期目标，儿童阶段也可能提前想“重建唐门”“进入舰队”或处理后来战争。
3. 场景知识读取人物定义中的最终 `factionIds`，覆盖已经正确过滤的NPC当前势力。
4. 初识关系向量直接写入后来感情、身份揭晓和阵营冲突结果。
5. `occurredCanonEvents`包含世界已经发生但玩家并不知道的秘密事件；`futureCanonLocks`又把未来事件标题和参与者完整发送给模型。
6. 部分人物始终使用最终姓名或称号，例如古月提前显示成古月娜、冻千秋提前显示成白秀秀、王冬提前显示成唐舞桐。
7. 两个已证魂力节点之间使用未来节点线性插值，产生原著没有给出的“精确当前等级”。

## 修复

### 人物人生阶段

新增 `character-life-stages.ts`，对主要跨身份人物按年份与日序保存：

- 当前公开姓名
- 当前目标
- 当前可证公开势力
- 生效与结束日期

首批覆盖唐三、唐昊、霍雨浩、王冬/王冬儿/唐舞桐、萧萧、唐舞麟、古月/古月娜、蓝轩宇、冻千秋/白秀秀和雪清河/千仞雪。

没有人工阶段资料的人物使用保守状态：儿童只处理家庭、觉醒与学习；成年人物只使用当前已证实力节点和职责，不再回读终身目标。

### 向量知识

- 删除会泄漏未来的终身人物核心文本。
- 人物向量改为当前人生阶段切片，不提供后来姓名、称号、武魂变化、关系结果、势力归属和目标。
- 包含尚未公开姓名的实力快照不写入模型向量。
- 关系向量只描述当前已发生关系，并调整初识日期；不再写“后来成为伴侣”等结果。
- 历史事件只有进入玩家新闻或可靠情报后才能召回；仅存在于隐藏世界的旧事不能召回。

### 模型上下文

- `occurredCanonEvents`只发送玩家已经通过亲历、消息或调查获知的事件。
- 未来事件只发送数量与禁止猜测规则，不再发送标题、参与者和结果。
- 场景NPC使用当前公开姓名、当前目标与当前势力，不读取最终人物定义。
- 正文和AI记忆同时审查未来姓名、称号、等级和势力归属。
- 交谈、拜师、攻击和NPC规划只按当前公开姓名匹配；后期姓名必须先有高可信身份核验，不能靠玩家输入一个名字反向解锁。

### 规则与前台

- 古月在东海零班阶段只显示“古月”，不显示古月娜、银龙斗罗或传灵塔归属。
- 冻千秋改名事件前只显示“冻千秋”。
- 王冬、王冬儿、唐舞桐按阶段切换。
- 雪清河的公开身份可以被认识，但千仞雪真实身份需要密档、身份核验或交叉证据。
- 未到第一个可靠实力节点时，NPC等级保持“实力未核实”，不再用未来等级反推。
- 玩家仅输入一个未知未来势力名称不会自动获得该势力资料；必须属于当代公共常识或已有可靠情报。

## 旧存档

Schema 35会：

- 重建纯原著关系基线。
- 把没有可靠身份核验证据的后期姓名改回当前公开姓名。
- 清理旧正文、任务、新闻、NPC记忆和长期摘要中的未来姓名、未来事件标题及未形成势力归属。
- 保留玩家已经通过高可信密档、身份核验或交叉证据确认的秘密。
- 保留玩家真实因果已经改变的人物目标和势力状态。

## 自动证据

- 六岁唐三不再拥有唐门或昊天宗当前归属。
- 20003年的古月不召回古月娜、银龙王、银龙斗罗或传灵塔权力资料。
- 30001年的冻千秋不显示白秀秀、舰队伴侣等后期信息。
- 阿银旧案即使已在隐藏世界发生，玩家未获得可靠消息时也不能从向量库召回。
- 地方支线、人物规划和传播链继续使用当前NPC势力，不使用最终人物定义。

## 剩余边界

160名人物已全部停止使用终身目标和最终势力作为当前模型输入，但人工精细人生阶段目前优先覆盖主要跨姓名、跨阵营角色。其他人物在缺少逐阶段原文证据时采用保守目标，而不是凭推测补全。后续可以继续增加可靠阶段资料，不能为了“内容丰富”重新引入未来结果。
