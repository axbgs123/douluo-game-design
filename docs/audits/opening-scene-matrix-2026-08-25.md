# 开局身份—武魂—主持机构矩阵审计

日期：2026-08-25

## 修复目标

开局不再只替换名词。同一身份、武魂类别和主持机构必须共同决定显形动作、复核方式、资源问题、近期目标与推荐行动。

## 武魂显形矩阵

| 类别 | 当前显形与测试重点 |
|---|---|
| 器武魂 | 器物在掌中成形；检查形态、重量、结构、魂力反应与收放 |
| 兽武魂 | 兽影与身体附体变化；检查兽化部位、本能控制、力量与收放 |
| 本体武魂 | 身体、感知、骨骼、声音或呼吸直接变化；禁止写成托在掌心 |
| 植物武魂 | 根、茎、叶、藤或花生长显形；检查环境反应与消耗 |
| 食物武魂 | 完成第一次制造；检查速度、消耗、保存与食用安全，不当场盲吃 |
| 元素武魂 | 以气流、光影、温度或元素波动显现；检查范围、稳定性与收放 |

隐藏的第二武魂只表现为主角能感到的另一股回响。主持者未看到第二次显形时，不得知道其名称、类别或能力。

## 身份与现实目标

| 身份类型 | 第一阶段问题 |
|---|---|
| 平民公共觉醒 | 学院名额、路费、食宿、监护与第一魂环协助由谁承担 |
| 宗门或机构内部 | 本方导师、训练场、资源额度、保密、猎魂护送与内部责任；不重复“加入本宗” |
| 皇室与贵族 | 家族教师、资源、同辈排序、继承压力与个人选择边界 |
| 无身份穿越者 | 今晚住处、现场见证、临时凭据与是否登记异界来历 |
| 魂兽养育 | 兽群保护边界、人类身份、钱币礼节与是否接触人类修炼体系 |

斗二以后公共觉醒按各时代的地方魂师机构、初等学院、联邦儿童觉醒中心等渠道处理，不再沿用斗一武魂殿巡查执事。

## 可执行闭环

专属目标不是只换文案。程序新增四类开局行动结算：

- 觉醒后能力复核
- 建立临时大陆身份
- 核对开局培养条件
- 确认兽群与人类边界

最后的主修和公开范围选择继续写入武魂状态。每步完成后推进章节目标并留下系统收据。

## 非悬疑边界

普通成长、测试和培养场景中，单独出现“恐怕不只是”“一定还藏着”“新的谜团”等强行悬疑句即触发重写。旧存档中已经生成的“本体武魂托在掌心”“宗门内部谈学院名额”和强行魂环谜团会在Schema 38加载时修正。
