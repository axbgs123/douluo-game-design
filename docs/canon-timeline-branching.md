# 原著时间线分支结算

## 目标

原著提供世界规则、人物惯性与重要事件的初始条件，不是无法改变的录像。玩家真实改变关键人物、势力、地点、权限或资源后，后续事件必须从当前世界状态重新结算。

## 因果链

每条玩家影响保存发生日期、地点、受影响人物、受影响势力与强度。原著节点到期时只计算和该节点存在人物、势力或地点连接的影响；无关的全局“世界偏差”不能改写事件。

当关联影响没有越过节点惯性时，事件仍会发生，但公开消息会注明部分参与条件已经改变。当影响越过门槛时，程序按当前条件形成三类分支：

- 延后：核心参与条件仍存在，但准备、权限、资源或关系已经不足。事件进入新的日期后再结算。
- 替代：人物和势力仍在活动，但阵营、资源或利益结构已改变，形成不继承原结果的替代行动。
- 取消：关键参与者死亡、失去活动条件，或核心组织与地点条件已经失效，原事件不再发生。

## 分支后果

分支结算不是一条提示文字。程序会同时：

1. 写入结构化 `canonTimelineBranches` 记录。
2. 更新仍存活参与者的当前目标并废止旧行动计划。
3. 生成可继续介入的历史分支事件。
4. 更新历史影响指标。
5. 生成衰减后的分支因果，继续参与后续相关原著节点判断。

因此，玩家改变唐三的早期入学条件后，影响不会只停留在诺丁学院；只要因果强度和人物连接仍然成立，后面的师徒、猎魂、史莱克聚首等节点都会从新状态重新判断。

## 信息边界

远方分支可以在隐藏世界正常结算，但只有公开事件、玩家在场、已知参与者或已有直接因果来源满足可观察条件时，才会进入消息、前台原作因果、AI提示词和向量召回。玩家不能通过模型上下文提前得知远方秘密分支。

## 存档

Schema 36为旧存档补充空的时间线分支账本，不删除已有因果足迹。旧存档下一次触发原著节点时会按现有玩家影响正常生成分支。
