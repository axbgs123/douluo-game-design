# 2026-08-27 Xiaomi MiMo-V2.5-Pro 对照冒烟

## 边界

- 官方按量接口 `https://api.xiaomimimo.com/v1`，模型 `mimo-v2.5-pro`。
- 使用与 DeepSeek 相同的冻结四时代存档、玩家行动、三层召回、程序结算和正文审校，不保存提示词或正文。
- 官方国内价为缓存未命中输入3元/百万 tokens、输出6元/百万 tokens。本报告将全部输入按缓存未命中计算，因此是费用上界。价格来源：<https://mimo.mi.com/docs/zh-CN/price/pay-as-you-go>。

## 接入适配

- 正式服务根据小米 Base URL 改用 `max_completion_tokens`，DeepSeek 继续使用 `max_tokens`。
- 真实模型冒烟只放行两组已核对的官方组合：DeepSeek V4 Flash 与 Xiaomi MiMo-V2.5-Pro；按各自官方价格单独结算预算。
- MiMo 使用非思考模式与 `json_object`，避免把额外思考成本与过度分析带入普通小说场景。

## 第一批：四时代各两回合、只允许一稿

- 16次请求，无HTTP失败；输入132,160 tokens，输出4,410 tokens。
- 费用上界0.422940元。
- 通过4/8：斗四2/2，斗二与斗三各1/2，斗一0/2。
- 斗一两稿均返回无法解析的JSON；斗二有一稿被“没有导师”称谓误审拒绝；斗三有一稿将玩家调查拖到后半段，并出现斗三当下仍由“武魂殿执事”办事的跨时代风险。

## 中间修正

- “没有导师”不再被当作新编姓名。
- “武魂殿执事”不再误报为姓名；新增真正的年代门禁：斗二至斗四不得把武魂殿执事/分殿当作当代登记、主持、上报或招揽机构；明确的历史记录仍可提及。

## 第二批：斗一至斗三定向复测、最多两稿

- 14次请求，无HTTP失败；输入130,438 tokens，输出4,890 tokens。
- 费用上界0.420654元。
- 通过4/6：斗一2/2，斗二与斗三各1/2。
- 斗二剩余场景仍因正文JSON损坏失败；斗三剩余场景两稿都没有在前半段写出玩家亲自调查的可见证据，审校拒绝正确。

## 总结

- 两批合计30次请求，输入262,598 tokens，输出9,300 tokens，费用上界0.843594元，低于1元授权上限。
- 按8个目标场景汇总，6/8最终获得已接受正文；斗二第二回合与斗三第一回合未通过。
- MiMo 在斗四两回合和修正后的斗一两回合表现稳定，但长正文JSON可靠性低于当前DeepSeek对照，且调查行动所有权仍会失败。
- 因报告故意不保存正文，本次只能比较结构可靠性、原著门禁、召回和审校闭环，不能声称MiMo的文笔优于DeepSeek。
- 当前不建议将MiMo-V2.5-Pro设为默认正文模型。若继续研究，应先试验小米Responses API的结构化输出或函数调用封装，解决JSON损坏后再做隐去模型名的人工文笔盲评。
