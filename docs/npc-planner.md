# NPC欲望—责任—资源行动规划器

## 目的

NPC不能只靠随机概率移动、换目标或向玩家发布任务。规划器把人物性格与原著目标转成可执行六环：欲望、责任、信息、权限、资源、行动与后果。

## 隐藏状态

每个在世且属于当前时代的具名NPC维护 `activePlan`：

- `desire`：当前真正想推动的目标。
- `responsibility`：家庭、学院、宗门、军方或职业义务。
- `informationBoundary`：亲历、可靠转述和职责信息；不含全知资料。
- `authority`：当前身份与实力真正能调动的范围。
- `resources`：实力、势力渠道、所在地资源和玩家互动记忆。
- `nextAction`：下一项可执行动作。
- `targetLocationId`：计划需要抵达的地点。
- `deadlineOrdinal`：计划检查期限。
- `status/progress/lastOutcome`：执行、受阻、完成和最近后果。
- `playerImpact`：玩家因果如何改变该人物可用条件。

完整计划属于隐藏世界状态，不直接展示给玩家。玩家只能从当面动作、对话、情报、移动、组织决定和后果观察人物意图。

## 行动规则

- 保护型人物会检查风险、询问受保护者的选择、调整护卫和退路。
- 调查型人物会追查来源、交叉核验，再决定继续、暂缓或求助。
- 修炼/教学型人物会训练、复盘、调整方法并正式测试。
- 组织型人物会核对资源与意见、处理分歧并执行有依据的决定。
- 对抗型人物会先查行踪、实力、保护者和代价，再寻找盟友、地形或信息差，最后决定试探、谈判、伏击或撤退。

计划目标不在直达路线时，NPC不会瞬移，而会因路程、许可、交通或带路人不足进入“受阻”。

## 世界联动

- 30日世界周期从符合年代和生存条件的NPC计划中执行行动。
- NPC移动、主动请求和NPC—NPC关系变化引用当前计划，而不是泛化随机理由。
- 两人职责或目标一致时更容易合作；同地争夺资源、权限或行动先后时可能冲突。
- 玩家影响相关人物后，新计划会记录玩家造成的条件变化。
- 当前地点的NPC计划进入小说逻辑包和叙事上下文，但只能通过可观察行为表现，不能直接泄露内心或秘密。

## 与卷级导演的关系

卷级导演组织主角长线；NPC规划器保证对手、导师、家人和同伴拥有自己的长线。两者相遇时形成剧情，但任何一方都不能覆盖程序结算或替玩家选择。
