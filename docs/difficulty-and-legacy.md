# 难度与多周目传承

## 已确认规则

- 游戏提供五档难度。
- 完成一局可获得一种局外点数。
- 局外点数能够调整下一局随机结果的权重。
- 局外系统还可以解锁出身、武魂、天赋、遗物和知识图鉴。
- 难度一和难度二原则上不限制局外加成；高难度是否使用点数上限、槽位或收益递减待确认。
- 新一局可以进入全新世界线，也可以选择成为上一局角色的后代、弟子或继承者。

## 设计原则

- 局外成长增加选择和构筑可能性，不保证每局直接获得更高战力。
- 调整随机权重不删除低概率结果，除非玩家主动关闭某类内容。
- 高难度应提高风险和决策压力，同时提供更高局外收益。
- 继承同一世界时，旧角色、关系、势力和历史改变必须从存档真实延续，不能只写一句背景介绍。
- 防止多周目累积让原作惯性和成长过程失去意义。
