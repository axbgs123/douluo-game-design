# 首批修仙设定参考包

## 使用原则

- 只参考作品的世界规则、体质、功法、技艺、资源生态和成长结构，不引入原作人物本人。
- 不复制原作剧情或大段文本；所有内容都要转化为可验证、可成长、受斗罗世界约束的游戏规则。
- 一个参考包提供能力模板与限制条件，不保证玩家每局都能抽到。
- 专有能力必须经过公开版本的版权与命名复核；必要时使用原创名称和重新设计后的表达。

## 首批六个参考方向

### 1. 《凡人修仙传》方向

- 参考点：灵根差异、资源驱动成长、炼丹、炼器、阵法和谨慎求生。
- 斗罗化：灵根作为隐藏资质；丹器阵形成副职业；稀缺材料、失败率和时间成本由规则层结算。
- 设计价值：适合低天赋开局和长期积累型人生，不必依赖原作人物或剧情。

### 2. 《完美世界》方向

- 参考点：至尊骨、血脉、搬血与洞天式肉身成长。
- 斗罗化：至尊骨可成为特殊魂骨/体质，洞天可成为受魂力等级约束的并行修炼节点。
- 设计价值：提供强潜力、强代价和被觊觎风险并存的成长路线。

### 3. 《遮天》方向

- 参考点：特殊体质、苦海至道宫等人体秘境，以及资源与寿命压力。
- 斗罗化：人体秘境成为并行修炼子系统，每个秘境必须与魂师等级、身体承载和天地资源匹配。
- 设计价值：让“强大体质”不等于开局无敌，并自然产生修炼成本和世界规则冲突。

### 4. 《仙逆》方向

- 参考点：意境、道念、神魂与炼体的长期演变。
- 斗罗化：意境只能由经历、认知和关键抉择形成，不能通过随机抽取直接满级；可映射为领域、精神系魂技或自创魂技。
- 设计价值：把剧情选择转化为可积累的战斗与人格能力。

### 5. 《诛仙》方向

- 参考点：门派传承、法宝养成、阵法以及正邪立场冲突。
- 斗罗化：法宝作为器武魂、伴生器或可成长装备；阵法依赖多人、地形和资源；立场由实际关系与事件决定。
- 设计价值：适合宗门生活、关系网和长期装备养成。

### 6. 《星辰变》方向

- 参考点：星辰炼体、体内世界和以身体为核心的突破道路。
- 斗罗化：体内世界只能从极小雏形成长，受魂力、精神力、身体强度和稀有资源共同限制。
- 设计价值：提供不依赖传统武魂品质的另类成长路线，但必须承担高资源和高失败风险。

## 初步平衡规则

- 每种高价值设定同时生成至少一项资源约束、一项成长门槛和一项可被敌人利用的风险。
- 若设定层级远高于斗罗，只保留残缺本源或成长种子；完整力量不直接进入世界。
- 外来修炼体系不能跳过魂师世界的身体承载、社会关系、资源取得和时间流逝。
- 外来势力、怪物或器物是否跟随出现，由开局锁定的因果包决定，不在中途为了剧情方便临时追加。
