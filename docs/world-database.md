# 第一部世界资料库

游戏把“原作资料”和“某一局发生了什么”分开保存。前者是稳定基线，后者允许被玩家改变。

## 原作基线

服务启动时会把 `server/data/world.ts` 写入 SQLite：

| 表 | 内容 |
| --- | --- |
| `canon_characters` | 重要人物身份、别名、武魂、性格、目标与初始位置 |
| `canon_power_snapshots` | 人物在不同年份的魂力或实力描述 |
| `canon_factions` | 势力立场、资源、活动区域和原作惯性 |
| `canon_locations` | 地点、危险度、连接路线与旅行时间 |
| `canon_events` | 历史事件年份、参与者、地点与惯性 |
| `canon_soul_beasts` | 栖息地、年限、属性、危险度与可能魂技 |

资料库目前收录第一部核心人物及支撑完整游玩闭环的地点、势力、事件和魂兽。它不是原著全文副本，也不会把玩家未知的信息直接显示在界面上。

## 单局世界状态

每个存档的 `state_json` 记录：

- NPC 是否存活、当前位置、当前实力、目标、阵营和对玩家态度。
- 已发生、被压制或被蝴蝶效应改变的历史事件。
- 玩家发现的地点、人物和公开消息。
- 健康、疲劳、修炼进度、战斗内部值与猎魂阶段。
- 关系、任务、背包、魂环、伤势和人格行为证据。

程序只把角色当前能判断的信息组装成 `GameView` 返回网页。NPC 的隐藏目标、真实态度、未触发金手指、战斗生命值和未来事件不会发送给前端。

## 时间与实力

玩家行动会推进分钟、日期和年份。跨年后，人物年龄与 NPC 实力按资料节点更新；跨过历史年份时，事件会结合原作惯性和当前世界偏差结算。重要事件更难被小幅行为改变，但没有绝对剧情保护。

## 扩展方式

增加人物或事件时先修改 `server/data/world.ts`。服务下次启动会按 ID 更新资料表，不会覆盖已有存档中的单局经历。第二部入口应使用独立时代资料集，并通过跨时代推演把上一局结果转换成新的历史基线。
