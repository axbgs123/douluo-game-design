# 斗罗世界知识向量层

## 产品原则

用户确认的世界运行方式：

1. 不预设玩家必须知道或不知道原著剧情，知识边界由具体身份、亲历、告知和调查决定。
2. 玩家是否接触主角团、加入哪一方、夺取或放弃何种机缘完全自由。
3. 除力量与时代等少数底层规则外，人物命运、关系、势力和历史均可改变。
4. 原著人物按斗罗世界中的性格、年龄、目标、利益、权限和资源真实行动，不围着玩家转。
5. 重要原著事件保持历史惯性；普通人物、关系、资源和地方事件持续自主变化。玩家形成足够因果后，重要事件也从新状态重新推演。

## 两层记忆

### 全局斗罗知识

SQLite `canon_knowledge_vectors` 保存结构化、概括化的世界知识，不保存原著正文：

- 人物：当前时间片的公开姓名、性格惯性、当前目标与当前可证公开势力。
- 人生时间线：各原作年份的年龄阶段、当前公开身份和已证魂力或实力状态；不使用未来节点插值当前等级。
- 势力：组织性质、总部、存续年代、资源与制度利益。
- 地点：时代、区域、危险与进入条件；路线和旅行时间属于游戏规则层，不作为原著事实入库。
- 原著事件：时间、地点、参与者、公开结果和惯性强度。
- 魂兽生态：栖息地、属性、年限、危险与可能魂技方向。

每回合按时代、年份、当前地点、已知人物、已发现地点与玩家行动召回最多 10 条。80个地点会按实际存续拆成101条年代切片，使天斗城等跨时代地点在不同政体下使用不同描述；隐藏人物、未来事件和未发现地点不会只因向量相似而进入模型。

人物知识同样采用人生阶段切片。终身人物定义中的最终称号、全部武魂、全部势力和长期结局不直接进入模型。王冬/王冬儿/唐舞桐、古月/古月娜、冻千秋/白秀秀、雪清河/千仞雪等按当前公开身份切换；没有精细阶段证据的人物采用保守当前职责，不根据后来状态倒推。

原著事件只有在玩家新闻或可靠情报中出现后才能召回。提示词不再携带未来事件标题和参与者，只保留程序内部年代拦截。

地点和势力逐项保存 `provenance`：

- `原著`：名称与基本身份有本地原著文本依据。
- `原著归纳`：基础地理或势力可证，但完整标签、用途或消歧名是项目归纳；模型不得称为原著原话。
- `原创`：同人新增地点或势力，可以参与当前世界运行，但模型必须明确它不是原著既有专名。

社会运行与异常反应已经拆到独立 `world_logic_vectors`，避免把原创游戏逻辑混写成原著事实。原创地点因需要参与场景检索仍保存在结构化世界知识表中，但检索文本、元数据和模型提示都会明确其原创身份。
具体触发、资源倾斜和敌对升级规则见 `world-logic-vectors.md`。

### 单存档事实

`vector_memories` 保存玩家已经造成的行动、关系、承诺、情报和历史偏转。全局知识与存档冲突时，当前结构化存档与程序结算优先。

## 人物与关系解释

- 性格是行为惯性，不是固定台词或永不变化的标签。
- 人物在不同年龄、职位、实力、伤势、关系和风险下会改变手段。
- 友情、信任、尊重、敌意和感情必须由共同经历与可追踪后果形成。
- 原著关系是人物初始历史，不是强制玩家复刻的轨道。
- 角色只根据亲历、告知、职责档案、可靠调查和公开传闻行动。

## 版权与事实边界

知识向量来自项目现有结构化资料和经原著核验后的概括，不复制原著段落。原创社会运行法则明确作为游戏模拟规则使用，不冒充原著逐字设定。资料仍需持续按斗一至斗四分别核验。
