# 地方事件专属后果与连锁影响

## 目标

事件无人处理后不能统一写成“事情自行收场”。程序必须说明谁受损、什么资源变化、哪个制度被追责，以及新局面如何继续影响玩家生活。

## 后果账本

`HiddenWorldState.localConsequences`保存：

- 来源事件与地点
- 供需、治安、伤亡、制度、关系、势力或生态类型
- 具体后果摘要
- 1—5影响强度
- 药材、金属、粮食、魂导材料和日用品供需变化
- 地方风险变化
- 开始与消退日期

手记页只显示玩家当前所在地可以观察到的生效后果；远方后果不会自动泄露。

## 当前专属事件

- 失踪的采药队：家庭生计中断、药材短缺、二次搜寻。
- 魂兽越界：耕地减产、粮价压力、兽径改变、临时猎魂队。
- 学院名额争议：名额冻结、招生信誉受损、家长联名复核。
- 商路扣押：货物受潮、运输停摆、药材与日用品涨价、责任追偿。
- 受伤的陌生魂师：治安盘查、救治与装备记录、无人认领储物器。
- 宗门招募：年轻成员增加、含糊契约、家庭退宗争议。
- 旧矿洞异响：塌方、封矿、矿工停工、金属短缺、旧支洞。
- 来历不明的挑战者：地方名声受损、同龄人竞争、公开选拔战。

上述八类是四时代都可能出现的地方生活事件。事件池还按时代和技术制度隔离：

- 斗二：魂导工坊核心阵法事故、极北补给延误、内院核心培养名额争议；魂灵适配实验只在公元纪年 10005 年后进入事件池。
- 斗三：升灵台紧急退出异常、斗铠材料批次污染、机甲驾驶证代考、传灵塔魂灵合同投诉。
- 斗四：星舰补给延误、模拟舱精神过载、真实航时登记争议、外星生态样本隔离破损。

时代专属事件同样拥有伤亡、制度、供需、关系、治安或生态后果及可追索的后续任务。斗一不会提前出现魂导工业、魂灵、升灵台、斗铠、机甲、星舰或跨星球样本制度。

未知事件按地方、势力、人物和历史前兆四类生成不同默认后果，不再共用一句文本。

## 玩家选择

- 拒绝：只记录拒绝与人物态度，事件继续倒计时；期限前仍可改变决定。
- 成功介入：按原行动结算改变结果，不应用无人处理后果。
- 介入失败：立即结算事件损失、持续后果与后续事件。
- 无人介入：到期结算专属后果。

## 连锁边界

每个事件最多生成两层自动后续，防止无限复制。后果到期后标记为已消退，但近期历史仍暂时保留。持续后果会进入市场价格、卷级压力、NPC计划、故事手记和AI正文上下文。
