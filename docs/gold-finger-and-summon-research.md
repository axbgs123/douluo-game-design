# 金手指与召唤机制调研记录

调研日期：2026-08-24。只归纳公开页面展示的机制结构，不复制小说正文、角色关系或具体奖励。

## 可复用结论

- 签到流的可辨识结构是“触发—反馈—应用”，地点和日期应当是实际条件，而非任意点击。[潇湘书院：签到系统流](https://www.xxsy.net/baike/axdj3tew0840)
- 模拟器流的核心差异是先经历一条可能人生，再按结果评分或保留信息；本项目只保留风险片段，不把模拟中的修为和物品带回。[哔哩哔哩公开简介：人生模拟器斗罗同人](https://www.bilibili.com/video/BV1W3TMzYECE/)
- 熟练度流强调同类行为的持续积累，并天然适合与魂环上限、技能分支绑定。[小说阅读网：我在斗罗肝经验](https://www.readnovel.com/bookquery/hvjdqbqb)
- 投资返还流依靠“选择对象—投入资源—对象成长—返还”形成关系驱动，但无限倍增会破坏角色自主性和战力体系，因此本项目把它拆为人情、契约、势力和经营机制，并设置对象、期限或证据限制。[潇湘书院：投资流简介](https://www.xxsy.net/baike/axdj3teuw50a)
- 抽取系统应公示池内容和概率，并设置真实可达的独立保底；重复物也应有明确补偿。[Supercell 卡包概率说明](https://ingame.support.supercell.com/clash-of-clans/zh_cn/articles/card-pack-drop-chances.html?q=1786716591)、[《守望先锋》补给概率与重复补偿](https://ow.blizzard.cn/news/264844/)

## 本项目采用的设计准则

1. 100 种金手指逐项声明触发、消耗、反馈、冷却和不可逾越的边界。
2. 名称、交互命令和完整机制签名均须唯一；自动测试阻止重复条目进入目录。
3. 金手指放大玩家的行动与选择，不直接覆盖魂力等级、魂环瓶颈、人物意志或世界因果。
4. 召唤到武魂时最低为紫色；金色、红色、七彩分别使用 10、40、80 抽独立保底。
5. 非保底抽取有 8% 概率转为遗物；优先给未拥有遗物，全部拥有后重复结果返还一张召唤券。
