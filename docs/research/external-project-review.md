# 外部互动小说项目对标

核对日期：2026-08-24。只借鉴通用工程方法，不复制世界观、剧情、提示词、素材或受版权保护内容。

## 参考项目

- [Project Lunar](https://github.com/horizonfps/project-lunar)：分层长期记忆、按场景检索故事卡、NPC 见证过滤、离屏世界演化。
- [Quilltale](https://github.com/Aeesh/quilltale)：结构化世界是事实源，状态变化先验证；用固定长局评估事实一致性、记忆利用率和无效状态迁移率。
- [RPGForge](https://github.com/want7up1/Rpgforge)：按模型职责记录调用令牌、延迟、失败与重写情况，以便定位质量和费用问题。
- [DAVE RPG 设计文档](https://github.com/emdalton/dave-rpg/blob/main/docs/design_v05.md)：将意图理解、规则结算、正文渲染拆分，非战斗社交同样拥有可验证机械结果。

## 与本项目的取舍

当前项目已经具备程序结算优先、第三人称正文渲染、NPC 情景记忆、见证过滤、章节摘要、事件存档、流式正文和状态审校，因此不引入多代理编排或外部图数据库，避免增加延迟、部署复杂度和 5 元模型预算压力。

本轮吸收两项不冲突能力：

1. 模型调用安全遥测：只记录职责、模型名、成功/失败、延迟、输入输出字符数和供应商返回的 token 数；不保存 API Key、提示词、推理内容或正文。
2. 已建立无付费模式也能运行的四时代固定长局质量指标，统计规则阻止率、账本/正文覆盖、叙事审校、NPC 记忆记录和非法数值状态。

外部项目的 LLM 直接判定战斗、由模型标签修改物品、自由生成世界事实等方案，与本项目“程序是唯一事实源”的目标冲突，不采用。
