本轮读取用户提供的本地压缩包，识别出《斗罗大陆》《绝世唐门》《龙王传说》《终极斗罗》和《神界传说》。原始文本与转换后的 UTF-8 文件只保存在 Git 忽略的 `source-materials/`，不提交、不复制长段，也不要求模型仿写作者独特句式。

## 当前游戏最早的叙事断裂

游戏此前虽然有严格逻辑包，却把“信息边界、证据、未决事项、因果痕迹”放得过重。模型因此倾向把普通旧物写成线索，把 NPC 写成隐瞒者，把每次结尾写成待解问题。逻辑没有错，前台类型却从成长同人偏成了解密任务。

原著早期章节的共同结构不是“先抛谜”，而是：

`生活处境 → 人物小欲望 → 具体劳动/学习/交往 → 武魂制度介入 → 身体、资源、关系或身份发生变化`

因此最小修复不是删除后台逻辑，而是把逻辑门禁与正文体验分层：后台继续核对人物凭什么知道、凭什么做到；前台先让角色吃饭、干活、训练、失望、被安慰、争输赢、拿到资源并承担疲惫。

## 分时代可执行转化

### 斗一

- 开局先让家庭、生计、村长、铁匠活计和孩子的个人目标成立，再解释魂师等级。
- 成长需要可数的劳动过程，并让劳动改变家庭关系、食物、身体和能力，而非只加进度条。
- 猎魂不是点地图：手令、市场、补给、路程、导师知识、目标习性和撤退判断共同构成冒险。
- 战斗信息在危险中使用；先知道弱点不等于必胜，角色仍会误判、逃跑和利用随手物件。

### 斗二

- 弱者开局先写生活来源、食物、路途和自定门槛，让“变强”有现实重量。
- 技能可以先服务谋生和结识人物，再进入战斗价值；关系由具体帮助和性格碰撞形成。
- 强机缘必须服从身体承载、封印和阶段解锁，不能一次把百万年能力全部发完。

### 斗三

- 武魂觉醒后的失望不能在仪式结束时消失，要带回家，由父母、住房、饭桌和经济条件继续承接。
- 家庭、学院和职业劳动是力量成长的主要载体；饭量、工资、材料和训练后的身体感受都能增强代入。
- 同龄竞争者要在战后复盘对方，关系会从轻视变成不服、关注或认可，而不是只留下任务完成提示。

### 斗四

- 科技与制度通过岗位命令、设备操作、军衔责任和应急流程出现，不用百科条目代替现场。
- 工作关系与私人关系可以同时存在：公事口令之后仍有人情、调侃、偏心和生活安排。
- 大段时代背景只在当前行动需要时给出，且必须落回人物正在执行的职责和风险。

## 已落地检查项

1. 新增 `canonNarrativeProfile`，按斗一至斗四注入不同生活质感。
2. 区分生活成长、学院势力、修炼突破、战斗猎魂、调查悬疑五类场景。
3. 非调查场景若连续出现通用谜团话术，会触发正文重写。
4. 明确允许第三人称限知直接写主角已有依据的期盼、失望、满足、好胜、羞耻和判断；限知不再等于心理含糊。
5. 设定说明遵循“先有人物欲望和生活动作，再由正在办事的人解释一小段”。
6. 普通场景结尾允许落在吃饱、疲惫、关系变化、获得待遇或明确成长目标，不强制疑问钩。

## 不能照搬

- 不复制原著句子、段落、标志性桥段或作者说明。
- 不照搬部分早期网文中过量的全知解释、重复感叹和性别描写习惯。
- 不把原著主角专属机缘批量发给原创角色。
- 不用“像原著”作为破坏玩家自由、NPC 信息边界和程序结算的理由。
