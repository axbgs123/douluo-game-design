# 卷级故事导演

## 目的

单回合规则正确不等于长篇剧情成立。卷级故事导演把任务、人物压力、动态事件、资源变化和玩家选择组织成持续蓄压与兑现的故事卷，但不替玩家决定行动，也不修改程序结果。

## 六阶段

1. 立局：明确本卷目标、现实门槛、对抗压力和失败代价。
2. 主动推进：玩家采取能够改变条件的真实行动。
3. 阻力显形：资源、制度、人物或敌对方开始形成具体阻碍。
4. 局势扩大：阻碍影响更多人物、地点、关系或势力。
5. 阶段兑现：玩家取得资格、资源、突破、胜利或阶段真相。
6. 不可逆转折：加入或离开势力、正式拜师、公开秘密、改变关系、历史偏移或承担长期责任。

阶段表示当前剧情需要解决的问题，不是预写结果。导演2.0不再按第几次行动推进，而是逐级检查：主动行动、真实阻力/代价、能力/谈判/有权限者反应、实际兑现、玩家重大选择。没有相应证据，阶段停留原处。

## 推进依据

每次已提交行动先判断是否属于本卷主线。玩家主动处理失踪、商路等地方支线时，支线照常结算并改变世界，但不会让培养主线凭空升级。

主线行动再按证据分类：主动行动、能力证明、关系谈判、现实代价、外部阻力、外部反应、实际兑现和重大选择。阶段门槛为：

1. 主动推进：至少一次可结算主动行动。
2. 阻力显形：出现拒绝、等待、费用、风险、伤势或权限门槛。
3. 局势扩大：阻力后，能力证明、关系谈判和有权限者反应至少形成两类证据。
4. 阶段兑现：导师、名额、食宿、训练、身份或第一里程碑至少一项真实落地。
5. 不可逆转折：玩家亲自决定归属、公开范围或长期路线。

斗一至斗四使用不同开局合同：斗一落实工读名额、路费和猎魂条件；斗二核对武魂特征、学院食宿和当代培养路线；斗三依据免费义务教育处理魂师班选择与后续魂灵费用；斗四先处理觉醒记录、魂力测试和初等学院安排，不把蓝轩宇家庭的特殊保密选择泛化给所有人，也不把后期高能少年班提前到觉醒当天。

导演会从实际关系和同场人物中选择一名有职责或利益的人形成主动场景。主持者会要求复核与答复，监护人会问食宿、费用和安全，导师或机构只说明权限内条件；主动找来不等于玩家已经同意，也不保证收徒、资源或好感。

完成不可逆转折且主线任务已经闭合后，下一次主线有效行动才建立新卷，优先承接仍未完成的计划和当前人生目标。普通地方事件不会自动夺取主线位置。

## AI边界

每次正文生成都会收到当前 `storyArc`。模型必须让场景服务于当前目标和冲突，但不得：

- 伪造敌人或新事件
- 替玩家选择阵营、导师、感情或秘密公开范围
- 改写胜负、物品、关系、时间和资源
- 为了节奏强行制造失败或胜利
- 在正文中暴露“故事导演”“阶段”等后台字段
- 把等待回应的NPC主动要求写成玩家已经答应
- 把自主支线强行改写为当前主线

## 前台

手记页展示六阶段、剧情压力、本卷目标、下一阶段缺口、兑现账本、NPC主动场景、自主支线、不可逆转折、失败代价和最近主线证据。旧Schema存档加载时会从真实行动节拍重建证据；旧版仅靠行动次数获得但没有证据支持的阶段不会保留。
