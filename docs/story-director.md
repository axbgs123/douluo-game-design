# 卷级故事导演

## 目的

单回合规则正确不等于长篇剧情成立。卷级故事导演把任务、人物压力、动态事件、资源变化和玩家选择组织成持续蓄压与兑现的故事卷，但不替玩家决定行动，也不修改程序结果。

## 六阶段

1. 立局：明确本卷目标、现实门槛、对抗压力和失败代价。
2. 主动推进：玩家采取能够改变条件的真实行动。
3. 阻力显形：资源、制度、人物或敌对方开始形成具体阻碍。
4. 局势扩大：阻碍影响更多人物、地点、关系或势力。
5. 阶段兑现：玩家取得资格、资源、突破、胜利或阶段真相。
6. 不可逆转折：加入或离开势力、正式拜师、公开秘密、改变关系、历史偏移或承担长期责任。

阶段表示当前剧情需要解决的问题，不是预写结果。没有实际失败，AI不能为了进入“阻力显形”伪造失败；没有程序奖励，也不能为了“阶段兑现”送出资源。

## 状态

`GameView.storyArc` 保存：

- 卷号与标题
- 当前阶段
- 本卷目标
- 核心冲突
- 对抗压力
- 失败代价
- 承诺的阶段回报
- 不可逆转折方向
- 0—100剧情压力
- 已发生节拍
- 可追踪剧情证据
- 已完成卷标题

## 推进依据

每次已提交行动按程序结果分类为：推进、关系、受挫、升级、兑现或转折。导演只使用真实的行动收据和状态变化推进阶段。受伤、拒绝和失败提高压力；威胁与冲突扩大压力；获得资格、突破和履约降低压力并形成兑现证据。

完成不可逆转折后，下一次有效行动会建立新卷，优先承接仍未完成的任务、活动中的威胁和当前人生目标。

## AI边界

每次正文生成都会收到当前 `storyArc`。模型必须让场景服务于当前目标和冲突，但不得：

- 伪造敌人或新事件
- 替玩家选择阵营、导师、感情或秘密公开范围
- 改写胜负、物品、关系、时间和资源
- 为了节奏强行制造失败或胜利
- 在正文中暴露“故事导演”“阶段”等后台字段

## 前台

手记页展示六阶段、剧情压力、本卷目标、核心冲突、对抗压力、阶段兑现、不可逆转折、失败代价和最近剧情证据。旧Schema存档加载时自动补齐第一卷。
