# 地图与魂币依据

## 货币

本地原著文本明确写有铜魂币、银魂币、金魂币三种货币，换算为一金魂币等于十银魂币、等于一百铜魂币。程序统一用铜魂币保存余额，显示时再拆成三种原著名称。这样可以精确结算十个铜魂币的短工钱，也能直接显示宗门子弟携带的数枚金魂币。

原著同一段还写明，一个金魂币足够普通三口之家生活数月；魂士进阶为魂师后，每月可领取一个金魂币补贴。游戏的工作、补给和开局余额以这两个尺度校准，不引入金币、银币或信用点等新名称。

## 地图资料筛选

联网检索到的地图主要来自玩家整理和已发行手游。可辨认的大陆级地图包括[百度经验收录的斗一地图](https://jingyan.baidu.com/article/d169e1867f8683026611d8b6.html)、[《斗罗大陆：史莱克学院》官网世界图](https://dldlslkxy.cmge.com/)和[《斗罗大陆：斗神再临》地图介绍](https://www.9game.cn/dldldszl/5113680.html)。这些图在城市位置、等级区域和后加地名上并不完全一致，也没有提供适合本项目直接再发布的授权说明。

项目因此没有复制外部图片。游戏内地图是自有 SVG，外部地图只用于核对天斗帝国、星罗帝国、武魂城、星斗大森林和西海的大方向；宗门、学院、城市与险地的相对关系再用本地原著文本校正。原著没有给出精确经纬度，地图坐标只承担游戏导航，不宣称是官方比例尺。

## 游戏内边界

- 公共城市、公开宗门、学院、森林与海域默认可见。
- 冰火两仪眼、杀戮之都、昊天宗隐居地、裁决地牢和原创隐世宗门等地点，在角色知道或亲自到达后才显示。
- 地图持续标出主角当前位置、进行中任务、猎魂地点和可介入事件。
- 玩家可在任意位置添加最多三十个自定义标点；标点写入本地存档，点击已有标点即可删除。
- 三选一页面会把候选人的具体房屋坐标单独叠加到大陆图上。房屋坐标是所在地点附近的叙事坐标，不伪装成原著给出的精确门牌。
