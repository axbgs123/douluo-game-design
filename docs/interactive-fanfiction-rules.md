# 实时可控同人小说规则

这份规则用于约束程序、DeepSeek 提示词和人工验收。它不要求逐章复刻原著，但要求每一次偏离都能追溯到主角真正做过的事。

## 一、原作与偏离

1. 原作人物、势力、地点、实力节点和重大事件以资料库为基线。
2. 主角尚未接触相关人物、势力、地点或事件时，对应原作节点照常推进，不能因为全局“偏差值”自行改写。
3. 改写必须形成可见因果链：主角行动 → 被影响对象 → 影响强度 → 原作节点变化。
4. 人物未出生、势力未成立、事件尚未发生时，不得在当世叙述中把它们写成既成事实。
5. 原著留白允许原创，但新增人物与力量仍受时代、地理、资源和斗罗力量上限约束。

## 二、主角能动性

1. 玩家自由输入是核心，建议按钮只是当前处境下可执行的具体行动。
2. 每次关键选择至少改变时间、资源、关系、风险、线索或世界状态中的一项。
3. 选项要让玩家大致判断方向和代价，但结果可以出现符合逻辑的副作用。
4. 程序负责成功率、伤势、资源和历史结果；模型只负责理解行动与小说化表达。
5. 世界状态决定可用行动。角色不知道的信息不能成为建议，也不能进入其内心判断。

## 三、小说叙事

1. 正文采用第三人称限知，贴近主角当下能感到、想起和推断的内容。
2. 叙述使用角色姓名及“他/她”；第一人称只允许出现在人物对白中。
3. 每段推进要有场景、动作、反馈和新的选择依据，避免百科介绍和系统总结替代小说正文。
4. 原作人物保留年龄、实力、位置、知识边界、性格与利益；不能只剩标签或网络梗。
5. 主角必须有独立生活线。没有合理渠道时，不能靠巧合立即卷入史莱克主线。

## 四、开局与界面

1. 三个开局候选必须在家庭、具体归属、生计、眼前矛盾和先天征兆上形成实质差异。
2. “宗门附属村民”等泛称不得单独出现，必须写明宗门、属地和管理单位。
3. 姓名可修改；人生目标可从预设中选择，也可自由填写。
4. 性格题的已选状态必须一眼可辨，选择结果要影响开场建议和后续判定。
5. 关系、地图、任务和原作因果分别使用图谱、路线图、时间轴和因果链呈现。

## 调研依据

- Fanlore 对 canon divergence 的归纳强调：故事先以原作事实为基础，再从某个明确变化点分叉。<https://www.fanlore.org/wiki/Canon_divergent>
- ink 官方写作指南把分支、状态条件与可回流结构作为互动叙事的基础表达。<https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md>
- Emily Short 对高能动性叙事的讨论强调可操控行动、可理解的局势反馈，以及让玩家判断行为会把故事推向何处。<https://emshort.blog/2017/05/25/mailbag-high-agency-narrative-systems/>
- Interactive Fiction Technology Foundation 将互动小说概括为玩家通过文本输入或选择参与并影响故事的媒介。<https://iftechfoundation.org/frequently-asked-questions/>
