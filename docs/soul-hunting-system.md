# 猎魂与魂环吸收系统

## 设计依据

第一部原著中的猎魂并非“选择列表后获得技能”，而是一条完整因果链：魂师先确定发展方向和所需属性，再研究魂兽、准备手令与补给、前往栖息地、追踪和辨认目标、完成战斗与最后一击，最后独自承受魂环吸收，并处理伤势、关系和后续恢复。

原著素材还表明，魂环价值不能只看年限：武魂与魂兽特性是否适配、魂师身体与精神承载力、当前伤势、魂兽死亡时的怨念、高年限魂兽的精神冲击，以及不可更换的长期路线选择都应进入结算。

同人常在这一骨架上增加势力掌握的栖息地地图、原创但符合当地生态的魂兽、特殊武魂亲和、自愿献环、自凝或契约等路线。这些可以作为灵感，但必须成为有来源、有门槛、有代价的规则，不作为临时剧情福利。

## 七阶段流程

### 1. 调查

- 明确角色的发展方向、武魂短板、期望属性与可接受风险。
- 从导师、宗门、同伴、书籍、传闻、地图或系统获得候选魂兽情报。
- 情报包含栖息地、属性、可能年限、习性、弱点、法律限制和大致适配方向；准确度取决于来源。

### 2. 准备

- 处理猎魂手令、队伍、预算、交通、食物、药物、露营、追踪工具、陷阱和撤离路线。
- 队伍成员可能收费、提出条件或拥有自己的猎魂目标。
- 准备不足不会禁止出发，但会提高旅途、战斗、吸收和撤离风险。

### 3. 旅行

- 严格推进时间，结算道路、天气、交通、费用、补给和区域危险。
- 不同森林、山脉、湿地、荒漠和海域拥有不同魂兽生态、执法者与进入条件。

### 4. 追踪

- 根据足迹、气味、领地痕迹、食物链、声音和目击情报寻找目标。
- 可能误判年限、找到不合适个体、惊动天敌，或遇见计划外但更合适的魂兽。
- 稀有目标不保证在预定时间内出现，玩家需要决定继续、换目标或撤退。

### 5. 战斗

- 玩家可接受队友控制、削弱、治疗、侦察和救援，最后一击规则等待第 98 题确认。
- 战斗中可能发生目标逃跑、其他魂兽介入、对手猎魂队争夺、执法检查或队友受伤。
- 魂兽的死亡方式、怨念和玩家行为会影响吸收、魂骨概率、关系与道德记录。

### 6. 吸收

- 核心输入包括魂兽年限与品质、属性适配、身体强度、精神强度、年龄成熟度、伤势疲劳、武魂状态、魂兽怨念和环境安全。
- 超限吸收不是简单百分比抽奖：规则先模拟身体能量冲击，再模拟高阶魂兽可能造成的精神冲击。
- 一旦开始，通常无法取消。失败可能导致中断、伤势、永久伤残、武魂受损、魂力倒退或死亡。

### 7. 后果

- 生成并校验魂技、属性变化、武魂变异、魂力变化和恢复时间。
- 结算补给消耗、队友伤势、报酬、承诺、声誉、势力态度、执法问题和当地生态影响。
- 魂技效果不是单由魂兽决定，还受到武魂、年限、吸收状态和既有成长路线影响。

## 推荐系统

- 导师、宗门、同伴和特殊系统都可以提供候选目标，但推荐是世界内信息，不等于开发者公布最优答案。
- 每条推荐保存“来源、依据、可信度、信息日期和利益关系”，以支持过时情报、认知局限和潜在偏见。
- 推荐者可能因为知识不足、宗门传统、个人利益或恶意给出错误建议；规则层保存真实数据，叙事层只能说出该角色知道或愿意透露的信息。
- 玩家可以拒绝全部推荐、自行调查或临时改选遭遇到的魂兽。
- 推荐系统优先解释取舍，例如更高年限、更匹配属性、更安全吸收、更容易获得或更符合团队路线，避免只给单一战力排名。
- 知识足够高的角色可以预测候选魂兽的大致年限、可能魂技类型和主要适配方向，但预测不等于保证结果。

## 特殊魂环路线

- 除传统猎杀外，允许契约、自愿献环、自凝魂环等路线。
- 特殊武魂、血脉和金手指更容易解锁这些路线，但传统魂师也可能通过长期研究、稀有传承或特殊关系发现。
- 特殊路线不能免费跳过成长：需要对应理论、材料、对象同意、身体条件、时间与失败风险。
- 传统猎杀保留“需要魂环的魂师必须完成最后一击”的规则；队友可以控制、削弱、治疗、侦察和救援。
- 魂环开始吸收后默认不能由外力直接代替或接管。药物、阵法、同伴或系统能否介入取决于已存在的具体设定；通常只能改善事前状态、隔离环境或处理吸收后的伤势。

## 五档吸收难度

所有难度都使用同一套世界规则；难度改变信息透明度、安全修正和失败后果曲线，不因高速模式而变化。

| 难度 | 情报与预警 | 吸收安全修正 | 失败后果 |
|---|---|---|---|
| 爽 | 显示清晰风险等级、主要危险来源和安全建议 | 在合理范围内给予较宽容的承载判定 | 普通失败多为疲劳或可恢复伤势；永久伤残和死亡通常只在玩家明知致命仍强行尝试时出现 |
| 简单 | 情报较准确，危险行动会明确警告 | 小幅提高准备、药物和休息的有效性 | 严重伤势较少，准备充分时可获得一次较宽的救援窗口 |
| 标准 | 使用原著式不完全信息与正常承载判定 | 无额外修正 | 超限、重伤、属性冲突或强烈怨念都可能造成永久后果和死亡 |
| 困难 | 年限与适配情报更依赖调查质量 | 不降低世界标准，但准备失误更难补救 | 严重失败更容易升级为永久损伤，救援窗口更短 |
| 地狱 | 不提供脱离角色知识的精确风险，错误情报可能存在 | 无安全兜底，连续疲劳和旧伤会完整叠加 | 武魂受损、魂力倒退、永久伤残和死亡均按完整因果发生，且可能产生连锁后果 |

难度不能覆盖因果。例如“爽”难度下主动吸收明显无法承受的超高年限魂环仍可能死亡；“地狱”难度下准备充分、选择合理也不应凭空失败。
