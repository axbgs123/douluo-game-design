# 世界基本逻辑向量库

## 为什么独立分表

`canon_knowledge_vectors` 只保存概括化原著事实；`world_logic_vectors` 保存游戏如何根据目击、利益、权限、资源和风险推导反应。二者分开，避免把原创模拟规则冒充原著设定。

## 核心修正

“NPC不会因为玩家强大而自动送机缘、收徒或产生好感”过于绝对，现修正为：

- 罕见天赋和实力会立刻改变关注、尊重、投资、收徒、拉拢、竞争、嫉妒、忌惮与敌意概率。
- 有权限且有利益的人可能主动提供导师面谈、食宿、训练场、猎魂协助、材料额度和培养名额。
- 是否正式收徒、继续投入、产生私人好感或忠诚，仍取决于路线适配、共同经历、条件谈判、资源和风险。
- 敌对势力得知可靠消息后，可能监视、控制、绑架或暗杀；行动必须经过消息抵达、威胁评估、可达性和成本判断。

## 当前组成

- 26条人物自主、人际关系、势力制度、资源生活、信息传播和历史惯性规律。
- 30条天赋反应、培养争夺、敌对风险、秘密暴露、制度响应和社会反馈链。
- 384维本地混合向量，每回合按当前时代和场景召回Top 8。

## 双生武魂示例

公开双生或三生武魂：

```text
现场目击
→ 暂停普通流程
→ 备用工具复测
→ 控制围观与形成记录
→ 上报有权限者
→ 导师和势力评估路线、忠诚、资源与归属
→ 培养资源倾斜与招募竞争
→ 消息逐步传播
→ 敌对方评估拉拢、监视、绑架或清除
```

隐藏副武魂：没有目击、检测记录或可靠推断链时，外界不能精确知道，也不会触发对应争夺和暗杀风险。

## 程序状态

公开多武魂会写入：

- `talentResourcePriority`
- `talentRecruitmentPressure`
- `talentHostileRisk`
- `talentThreatStage`
- 多武魂培养复核任务与玩家已知情报

敌对风险按30日世界周期检查，从查问名册、陌生盯梢逐步升级到袭击准备。系统不会直接判定某个原著势力是幕后方；玩家必须调查证据，敌对行动也不能无成本连续出现。
