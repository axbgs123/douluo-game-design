# 完整版验收基线

本页把本轮的“10 分”拆成可以检查的行为，避免只用主观印象判断。

## 1. 是否符合最初预想：10/10 基线

- 第一部单独进入，从六岁武魂觉醒开始，觉醒时间限定在唐三前后 20 年。
- 玩家只指定性别、人生目标和性格答案；出身、武魂、魂力、征兆与隐藏传承三选一随机并可无限重抽。
- 程序负责魂力、时间、战斗、伤势、魂环、物品和历史结果，AI 无权改数值。
- 玩家可以自由行动，也能走学院、课程、拜师、宗门、势力、猎魂、承诺、事件和特殊体系等长期路线。
- NPC 在玩家视野外移动、改变目标、结交或敌对，地方事件即使不参与也会自行发展。
- 玩家影响会进入世界偏差和历史影响；重要原作事件有惯性，但不是不可改变的固定剧本。
- 死亡、复生、目标完成、成神、主动结束和时间线结束都能成为一局的结点。
- 周目结算得到传承点，能够购买永久强化、携带遗物、调整下局随机权重并积累图鉴。
- 标准模式保留过程，高速模式支持按月、按年和修炼至瓶颈的长程推演，基础概率不变。

## 2. 同人小说游戏的代入感：10/10 基线（已接 AI）

- 复杂输入先被整理成规则可识别的行动，再由规则结算，最后才写成正文。
- 叙事器能看到场景、人物性格、势力身份、任务、关系、世界事件和最近十二段经历。
- 长期摘要、未决线索、关键选择、章节名和 NPC 独立记忆随行动持续更新，不靠短聊天窗口硬撑连续性。
- 重要人物拥有各自的原作性格、当前目标、对玩家态度和亲历记忆；人物声音不共用一套模板。
- 隐藏冲突和未知情报不会提前发给网页或模型，玩家只能根据亲历、传闻和调查逐步认识世界。
- AI 只把已结算的事实写成第三人称限知小说，不凭空赠送力量、不替玩家成功，也不能覆盖原作资料库。
- 四时代共 4000 条规则可以被程序检索；每次只启用与当前行动有关的部分，并保留命中的规则编号用于调试。
- 后世技术、未出生人物、无来源外挂和直接宣称获得顶级力量会在模型调用前被拦截，并给出符合当前世界的替代行动。
- 模型正文必须通过第三人称、年代连续性、模板腔、感叹号和篇幅检查；未通过时使用程序叙事，不让错误内容写入存档。

## 3. 桌面界面：10/10 基线

- 中央区域只承担章节正文与行动，右侧区域集中人物、武魂、背包、地图、关系、任务、猎魂和世界状态。
- 正文独立滚动，建议行动和输入框固定在底部，长篇内容不会把核心操作挤出屏幕。
- 顶部同时显示地点、游戏速度、年龄、相对唐三的觉醒时间和当前原作年份。
- 关系、任务和世界标签用数字提醒变化；伤势、身份、特殊体系和当前事件都能在对应位置直接看到。
- 局外成长独立成完整面板，明确显示传承点、难度结算、永久强化、遗物和世界资料库。
- “故事手记”独立展示本章梗概、未决线索、关键选择、近期后果和连续性状态，不再要求玩家从长篇正文里反查。
- 当前以桌面端为验收目标；窄屏只保证可用，不作为这一版的视觉评分对象。
